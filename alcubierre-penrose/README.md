# When Warp Horizons Extend

Source, reproducibility package, and development history for

> **When Warp Horizons Extend: Curvature Boundaries of Alcubierre Spacetimes**
> Sergei Slobodov

## The result

Conformal diagrams of a superluminal Alcubierre bubble appear to continue past
its front and rear horizons.  That continuation exists in the 1+1 axial
reduction; the paper asks whether it survives in four dimensions, and settles it
as an exact alternative.

For a stationary scalar shift with a compact regular superluminal wall
`Sigma = {v = -1}`, a proper Hausdorff C^2 Lorentzian extension exists **if and
only if** `Sigma` contains an open planar cap on which the inaffinity
`kappa = -v_x` is constant and nonzero.  Such a cap is a genuine Killing-horizon
patch and continues through a finite transverse Kruskal aperture.  Otherwise the
spacetime is C^2-inextendible.  Ordinary radial Alcubierre walls contain no such
cap, so each is already its own maximal Hausdorff C^2 extension.  A compact
flat-capped example shows the exceptional branch is not vacuous.

## Reproducing the checks

```bash
cd paper/supplement
python -m pip install -r requirements.txt
python run_all.py
```

Outputs are written to `scripts/output/sech/`.  Every shipped output is
regenerated by this command; see `paper/supplement/README.md` for the script
map.  The global extension alternative is proved analytically in the paper — no
numerical claim enters that proof.

## Building the submission packages

```bash
python scripts/build_staging.py --target all
```

This rebuilds the arXiv and CQG staging directories and zips from `paper/`, then
extracts and compiles each to verify it stands alone.
