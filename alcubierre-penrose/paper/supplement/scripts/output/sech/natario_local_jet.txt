Natario front-axis local-jet check

Local data:
  X=-e_x,  d_x X^x=-kappa,
  d_y X^y=d_z X^z=kappa/2,
  d_yy X^x=d_zz X^x=-2*kappa/R_F.

Gamma^a_tt = [-kappa, 0, 0, 0]
Gamma^a_ty = [0, 0, 0, 0]
Gamma^a_tz = [0, 0, 0, 0]
Thus d_t is pregeodesic, q is proportional to exp(kappa*t),
and d_y,d_z are parallel along the axial generator.

R_tyty = -kappa*(3*R_F*kappa + 8)/(4*R_F)
R_tztz = -kappa*(3*R_F*kappa + 8)/(4*R_F)
Ric_tt = -kappa*(3*R_F*kappa + 8)/(2*R_F)
R_KYKY = -kappa*q**2*(3*R_F*kappa + 8)/(4*R_F)
