## The Four Closure Results

### 1. The raw source target is not representation invariant

For

```text

```

the compensating refactorization

```text
O' = A O,
B' = A^-T B
```

leaves the physical interaction unchanged but sends the source-only Gram
matrix to `W' = A W A^dagger`.  Its participation ratio changes under
nonunitary `A`.  Therefore `N_eff(W)` is not an invariant of the interaction
unless a canonical microscopic source/exterior metric is supplied.

The exterior-defined replacement is a coupling-weighted jump or process map.
With a shared exterior wave packet its one-use Choi rank can be one no matter
how many preferred microscopic summands a model uses.  Exterior data cannot
reconstruct an arbitrary internal Kraus/source decomposition.

### 2. Aggregate Gaussian output data is non-identifying

Any probability vector `{f_i}` can decompose the same aggregate Gaussian
spectrum as

```text
S_i(omega) = f_i S(omega).
```

All such decompositions have identical flux, response when individually
calibrated, `g2(0)`, full `g1(tau)`, full `g2(tau)`, and every Gaussian Wick
moment, while

```text
N_eff = 1/sum_i f_i^2
```

is arbitrary.  The ordinary Gram tail is therefore not recoverable from the
aggregate Gaussian state.

Signed observables do not help generically.  HIGH and LOW response defects can
cancel exactly at `N_eff <= 2`; antibunched and superbunched fourth-moment
defects can do the same.  A hot thermal HIGH channel has `g2=2` by itself.

### 3. The active Hawking channel lies outside passive starvation

The anomalous Gaussian map

```text

|r|^2 = 1-gamma,
```

### 4. Entropy-rank precision exhausts a single evaporation history

Counting-limited accuracy `eta` requires at least `Omega(eta^-2)` events.  A
Schwarzschild black hole changes its mass fraction by


single unmodeled stationary window is limited to `eta >= O(S^-1/3)`.

Multi-setting response and tomography only increase the resource cost.  Full
rank can be an ensemble, cross-mass scaling, or model-side statement, but not
the literal stationary single-black-hole protocol previously suggested.
