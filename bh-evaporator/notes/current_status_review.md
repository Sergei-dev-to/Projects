# Current Status Review

## One-sentence status

The project now has a minimal fixed collision-Hamiltonian model that shows the
desired convex/control separation in a weak-coupling, many-channel working
window.

This is the first result strong enough to keep the paper path alive.

## What the project is about now

The claim is no longer:

```text
Page curves can occur without gravity.
```

That is already well covered.

The viable claim is:

```text
negative microcanonical heat capacity can dynamically control evaporation in a
non-gravitational finite quantum system, while Page-like radiation entropy is
computed from unitary emitted degrees of freedom.
```

This is a control-model claim, not a black-hole-information-puzzle solution.

## Evidence ladder

### 1. Original paper state

The old manuscript had:

```text
thermodynamic / spectral ingredients
synthetic Page-like curve
```

Weakness:

```text
the information-flow result was not generated by the same dynamics.
```

### 2. Re-randomized shell channel

The shell-channel model showed:

```text
convex S(E) -> rising emission schedule
unitary emitted bins -> Page-like S2_rad turnover
linear control -> no comparable acceleration
```

Weakness:

```text
random maps were redrawn during evolution.
```

Use:

```text
sanity check only.
```

### 3. Naive one-channel Hamiltonian

The naive Hamiltonian failed:

```text
one emitted label
fixed low-rank X_m
shrinking shell dimensions
large dark subspaces
```

Lesson:

```text
negative heat capacity is not enough; the evaporator needs outgoing channel
capacity and/or scrambling.
```

This was an informative failure.

### 4. Fixed high-rank channel

Fixed Stinespring maps with enough emitted labels recovered:

```text
Page-like turnover
convex/control acceleration separation
```

Important:

```text
re-randomization is not essential.
```

Weakness:

```text
still not Hamiltonian.
```

### 5. Multi-mode collision Hamiltonian

The reduced-density Hamiltonian simulation now gives:

```text
curvature 3, channels 8, g = 0.5:
  acceleration ratio: 1.138

linear control, channels 8, g = 0.5:
  acceleration ratio: 0.912
```

and:

```text
curvature 3, channels 8, g = 0.8:
  acceleration ratio: 1.080

linear control, channels 8, g = 0.8:
  acceleration ratio: 0.738
```

Interpretation:

```text
a fixed multi-mode collision Hamiltonian can show the desired separation in a
weak-collision working window.
```

## What is now established

Established in the engineered shell model:

```text
1. Radiation entropy is computed from dynamics, not drawn by hand.
2. Page-like turnover occurs generically from finite Hilbert-space competition.
3. Convex S(E) can produce an accelerating emission window.
4. Linear controls evaporate but do not show the same acceleration.
5. Outgoing channel capacity is necessary to avoid dark-subspace trapping.
```

## What is still engineered

The core density of states is still chosen by hand:

```text
D_m = round(exp[S(E_m)])
```

The shell Hamiltonian is still artificial:

```text
H_core = direct_sum_m E_m I_{D_m}
```

The radiation channel is engineered:

```text
many emitted labels per time bin
weak collision coupling
```

There is not yet:

```text
a natural local Hamiltonian
a physical condensed-matter implementation
a derivation of the Bekenstein-Hawking coefficient
a gravitational area law
an island/QES mechanism
```

That is fine if the paper is framed as a control model.

## Main caveat

The acceleration is a working-window effect.

It should not be stated as:

```text
power increases until the system is gone.
```

The correct statement is:

```text
in a finite energy window where S(E) is sufficiently convex, weak multi-mode
emission shows increasing emitted power; once finite depletion dominates, the
power falls.
```

This is analogous to using only the black-hole-like thermodynamic window, not
claiming a complete end-to-end black-hole evaporation history.

## Current paper viability

The project is now plausibly worth developing into a paper, but only after one
more numerical consolidation pass.

Minimum before writing results into `paper_v2`:

```text
1. Parameter scan over coupling g.
2. Parameter scan over emitted channel count.
3. Curvature/convexity scan.
4. More random seeds.
5. One clean figure showing convex vs linear:
   T(E), E(t), P(t), S2_rad(t).
6. Explicit statement of the weak-collision working-window regime.
```

If those scans support the same story, the paper has a defensible core result.
