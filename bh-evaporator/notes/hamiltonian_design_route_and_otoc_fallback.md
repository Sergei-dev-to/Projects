# Hamiltonian Design Route and OTOC Fallback

## Question

Can the shell mixer in Result 2A be made more Hamiltonian-like using known
results, without new numerics and without proving a custom expander-spin
scrambling theorem?

If that fails, can the OTOC/channel-scrambling route close the gap for a more
ordinary chaotic Hamiltonian?

## Short Answer

The Hamiltonian-design route gives a real upgrade, but it changes what is being
claimed.

The strongest citation-backed version is:

```text
H_mix(E) is sampled once from a known Hamiltonian ensemble whose time evolution
forms an approximate unitary design on the active shell.
```

Then the shell mixer is generated by Hamiltonian evolution, rather than by
declaring an abstract design unitary and taking its logarithm.

The cleanest fully time-independent version uses random polylog-local
Hamiltonians, following recent Hamiltonian-design results.  Constant-local
time-independent Hamiltonians are obstructed as a route to full global
2-design behavior.  Nearly time-independent or quenched Hamiltonian protocols
also generate designs, but they introduce time dependence or random evolution
times.

The OTOC route is useful as a physical diagnostic for candidate simple
Hamiltonians, but it does not close the deterministic expander-spin case by
citation alone.

## Candidate A: Nearly Time-Independent Design Hamiltonian

Nakata-Hirche-Koashi-Winter construct efficient unitary designs using
Hamiltonian dynamics.  Their construction includes a design Hamiltonian with
periodically changing two-local spin-glass-type interactions.

What it gives:

```text
Hamiltonian dynamics can realize approximate unitary designs efficiently.
```

Why it helps us:

```text
approximate design
  -> approximate-design decoupling theorem
  -> Page-purity and code-subspace information flow.
```

What it costs:

```text
the Hamiltonian is nearly time-independent / periodically changing;
the couplings are design-engineered;
it is more like a Hamiltonian implementation of the mixer than a natural
autonomous many-body model.
```

Assessment:

```text
Good as a Hamiltonian-realizable version of Result 2A.
Not the best if the target is a single autonomous Hamiltonian.
```

Reference:

```text
Y. Nakata, C. Hirche, M. Koashi, A. Winter,
"Efficient unitary designs with nearly time-independent Hamiltonian dynamics",
Phys. Rev. X 7, 021006 (2017), arXiv:1609.07021.
```

## Candidate B: Time-Independent Polylog-Local Hamiltonians

Cui-Schuster-Mao-Huang-Brandao study when time-independent Hamiltonian dynamics
can look Haar-random.  Their result has two sides.

No-go side:

```text
ensembles of constant-local Hamiltonian evolutions can be efficiently
distinguished from Haar randomness and fail to form a 2-design / PRU in the
strong global sense.
```

Positive side:

```text
random polylog-local Hamiltonians can form unitary k-designs and
pseudorandom unitaries under constant-time evolution.
```

What it gives:

```text
time-independent Hamiltonian evolution can generate approximate designs,
provided locality is increased mildly beyond constant locality.
```

Why it helps us:

```text
H_mix(E) can be a fixed time-independent Hamiltonian sampled once from such an
ensemble on the active microcanonical shell.
```

What it costs:

```text
the Hamiltonian is random;
the interactions are polylog-local rather than ordinary few-body local;
the result is very recent and should be treated as a theorem source to cite,
not as established black-hole folklore.
```

Assessment:

```text
Best citation-backed route to a fixed time-independent Hamiltonian mixer.
It is stronger than the abstract-log construction and weaker than a simple
deterministic expander spin Hamiltonian.
```

Reference:

```text
L. Cui, T. Schuster, L. Mao, H.-Y. Huang, F. Brandao,
"Random unitaries from Hamiltonian dynamics", arXiv:2510.08434.
```

## Candidate C: Quenched Temporal Ensembles

Recent work on temporal ensembles shows that a small number of chaotic
Hamiltonians, applied for random times, can generate unitary designs.

Zhou-Zhou-Sonner show that a three-step quenched protocol can realize
unitary `k`-designs, while a two-step protocol cannot in general.  Related
work studies single-quench or two-Hamiltonian variants.

What it gives:

```text
Hamiltonian evolution with a few quenches can generate unitary designs.
```

What it costs:

```text
random evolution times;
multiple Hamiltonian pieces;
an ensemble over protocols rather than one autonomous Hamiltonian.
```

Assessment:

```text
Useful if we allow Floquet/quench structure.
Less aligned with the autonomous-Hamiltonian goal.
```

Reference:

```text
Y.-N. Zhou, T.-G. Zhou, J. Sonner,
"Three Hamiltonians are Sufficient for Unitary k-Design in Temporal Ensemble",
arXiv:2604.04205.
```

## OTOC Fallback

The OTOC route remains:

```text
candidate chaotic H_mix
  -> OTOC decay / operator growth
  -> small channel mutual information
  -> Hayden-Preskill decoupling.
```

The second and third arrows are standard:

```text
Hosur-Qi-Roberts-Yoshida:
  OTOC decay in a unitary channel implies small mutual information between
  input subsystems and most output partitions.

Yoshida-Kitaev:
  OTOC decay guarantees faithful Hayden-Preskill recovery.
```

For sparse/expander graphs:

```text
Barbon-Magan:
  expander graph systems are proposed as horizon fast scramblers.

Bentsen-Gu-Lucas:
  sparse graphs can support logarithmic scrambling and operator growth.
```

What remains missing:

```text
a theorem that a specific deterministic nonintegrable spin Hamiltonian on a
deterministic expander graph has the OTOC/channel-decoupling bound needed by
the evaporation partitions.
```

Assessment:

```text
The OTOC route gives the right diagnostic for 2B, but it does not close 2B
using existing citations alone.
```

## Result-Level Interpretation

The useful refinement is a three-level hierarchy:

### Result 2A

```text
Abstract/theorem-backed shell mixer:
approximate design or tensor-product expander.
```

This is already in the draft.

### Result 2A+

```text
Hamiltonian-generated theorem-backed shell mixer:
time-independent random polylog-local Hamiltonian
or nearly time-independent design Hamiltonian.
```

This is reachable with citations.  It is the best next upgrade.

### Result 2B

```text
Simple deterministic expander spin Hamiltonian:
prove OTOC/channel decoupling for the evaporation partitions.
```

This remains open.

## Recommendation

Push the paper to Result 2A+ rather than all the way to 2B.

The clean paper statement would be:

```text
In the finite regulator, the in-shell mixer can be implemented either as a
standard approximate-design/tensor-product-expander block or by known
Hamiltonian design constructions.  A fully autonomous constant-local
many-body realization is a stronger microscopic problem and is not required for
the exterior evaporation result.
```

Then the discussion can say:

```text
Recent Hamiltonian-design results show that time-independent polylog-local
Hamiltonians can generate unitary designs, while constant-local
time-independent Hamiltonians are obstructed as a source of full global
2-design behavior.  Simple expander spin Hamiltonians remain a promising
physical route, with OTOC/channel-decoupling as the target diagnostic.
```

This is stronger than the current draft and still citation-backed.
