## Core Mathematical Fact

The fuzzy two-sphere at matrix size `N` is described by the matrix algebra:

```text
Mat_N.
```

Under the adjoint action of `SU(2)`, this algebra decomposes into angular
momentum shells:

```text
Mat_N = direct sum_{l=0}^{N-1} V_l,
dim V_l = 2l + 1.
```

Therefore:

```text
dim Mat_N = sum_{l=0}^{N-1} (2l+1) = N^2.
```

This is exactly the angular-shell count we wanted.

The fuzzy-sphere cutoff is:


## Evaporation As Matrix-Size Reduction

The proposed evaporation step is:

```text
Mat_N -> Mat_(N-1) + shell l=N-1.
```

Dimension count:

```text
dim Mat_N - dim Mat_(N-1) = N^2 - (N-1)^2 = 2N - 1.
```

This equals:

```text
dim V_{N-1} = 2(N-1)+1 = 2N-1.
```

So reducing matrix size by one removes exactly the outer angular shell.

This is cleaner than the pairwise connector model:

```text

incident graph edges.
```

## Softness Interpretation

The fuzzy-sphere matrix harmonics normally have Laplacian eigenvalues:

```text

```

So if they are ordinary field excitations, high `l` modes are not soft.


The fuzzy sphere supplies the finite angular basis and the shell count.

This remains the main physical assumption.
