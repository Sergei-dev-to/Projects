# Boundary Emission Hamiltonian Block Results

## Question

Can we replace the microscopic hard/soft emission isometry with an explicit
finite Hamiltonian pulse?

The previous merged diagnostic used:

```text
|i>_port -> |0>_port sum_h sqrt(p_h) |h>_hard |i,h>_soft.
```

with `p_h` computed from golden-rule entropy-ratio weights. This was still an
isometry inserted as a channel.

This note replaces that step with a local Hamiltonian block.

## Script

```text
sim/boundary_emission_hamiltonian_block.py
```

## Local Hamiltonian

For each microscopic emission, add fresh ancillas:

```text
flag in {in, out}
hard in {0, 1}
soft in {0, 1, 2, 3}
```

The Hamiltonian couples:

```text
|i, in, 0, 0> <-> |0, out, h, 2i+h>
```

with amplitude:

```text
sqrt(p_h).
```

Equivalently:

```text
H_emit = V + V^\dagger
```

where `V` is the hard/soft emission isometry.

At:

```text
theta = pi/2
```

the finite unitary pulse:

```text
exp(-i theta H_emit)
```

maps the input subspace to the emitted hard/soft record, up to a phase.

The script explicitly checks the local block:

```text
local Hamiltonian block error: 5.077e-16
```

So the channel is generated by a finite local Hamiltonian block.

So the Hamiltonian block reproduces the desired pattern:

```text

```

the expected behavior and the no-scrambling branch is not the physically
interesting case.

## Interpretation

This is the right kind of upgrade.

Before:

```text
hard/soft emission was an isometry.
```

Now:

```text
hard/soft emission is generated by a finite local Hamiltonian pulse.
```

The result is still modular, but it removes the most artificial channel step in
the microscopic information-flow diagnostic.

## What Still Remains

This is not yet one autonomous evaporator Hamiltonian.

Still modular:

```text
fresh emission ancillas are supplied each event;
the pulse time theta = pi/2 is chosen;
bulk-to-boundary mixing is a separate unitary step;
mass is updated externally between events;
the coarse L register is not dynamically updated.
```

So this upgrades:

```text
channel -> Hamiltonian block
```

but not yet:

```text
Hamiltonian block -> autonomous evaporator.
```

## Next Destination

The next jump would be to combine:

```text
bulk-boundary scrambling
boundary soft oscillator / qudit mode
bath modes
emission Hamiltonian block
coarse mass/register update
```

into a single repeated-interaction Hamiltonian model with explicit energy
labels.

The specific missing piece is energy conservation:

```text
the Hamiltonian block should exchange energy omega_h between a boundary soft
mode and a bath hard mode, rather than just emitting a hard label.
```

That is the next place where the model could either become genuinely physical
or reveal that the information channel is still engineered.
