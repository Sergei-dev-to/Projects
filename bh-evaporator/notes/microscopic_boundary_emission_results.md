# Microscopic Boundary Emission Results

## Question

Can the boundary-soft-mode picture support information flow, not just the right
emission energy scale?

After the golden-rule and boundary-mode diagnostics, the thermodynamic layer was
in good shape:

```text
bulk constrained entropy: S ~ L^2
boundary tension mass:    M ~ L
boundary soft modes:      omega ~ T ~ 1/L
2D bath power:            P ~ 1/M^2
```

The remaining question was whether microscopic boundary emissions can carry
information in a black-hole-like way.

## Model

Start with a bulk register maximally entangled with a reference:

```text
|Psi> = 1/sqrt(D) sum_x |x>_R |x>_B.
```

Each microscopic event emits from one boundary port qubit:

```text
|i>_port -> |0>_port sum_h sqrt(p_h) |h>_hard |i,h>_soft.
```

The hard qubit has fixed thermal weights:

```text
p_h = (0.75, 0.25).
```

The soft record purifies the port input and hard outcome. This is intentionally
minimal and diagnostic, not a full Hamiltonian.

Three variants were compared:

```text
none:
  no bulk mixing after the port is reset.

local:
  fixed nearest-neighbor two-qubit gates on a bulk chain.

scrambled:
  fresh Haar unitary on the full bulk register before each emission.
```

## Result

After three microscopic emissions, ensemble means were:

```text
variant      D_hard   I(R:hard_all)   I(R:pair_all)   I(R:bulk)
none         0.0000       0.0000          1.3863        4.1589
local        0.0000      -0.0000          2.5099        3.0353
scrambled    0.0000      -0.0000          2.9261        2.6191
```

Here:

```text
D_hard:
  trace distance of latest hard quantum from the target thermal distribution.

I(R:hard_all):
  how much reference information is visible in hard radiation alone.

I(R:pair_all):
  how much reference information is present in hard+soft emitted records.

I(R:bulk):
  how much reference information remains in the bulk.
```

The pattern is clear:

```text
hard radiation alone stays locally thermal and reference-decoupled;
hard+soft records carry information out;
scrambling controls how much bulk information reaches the boundary port.
```

The no-scrambling case emits only the initially exposed boundary bit:

```text
I(R:pair_all) = 1.3863 = 2 log 2
```

and then stalls.

The local and scrambled cases continue moving reference information into the
emitted hard+soft records.

## Interpretation

This is the first microscopic-emission diagnostic that connects the boundary
soft-mode fix to information flow.

It supports the layered picture:

```text
bulk scrambling moves information to the boundary;
boundary soft emission produces hard thermal quanta;
soft records purify the hard channel;
radiation information appears globally, not locally in hard quanta.
```

This is qualitatively black-hole-like in the limited Page-model sense:

```text
local Hawking-like quanta look uninformative;
unitarity is restored only in larger correlations.
```

## What This Does Not Yet Prove

This is still a diagnostic channel, not an autonomous Hamiltonian.

The following ingredients are still inserted:

```text
thermal hard weights p_h;
the hard/soft isometry;
the soft record dimension;
bulk-to-boundary mixing rule;
fixed number of emissions;
no actual energy bookkeeping per event.
```

So this should not be read as:

```text
we have a full microscopic evaporator.
```

It should be read as:

```text
the boundary-microscopic-emission picture is compatible with the desired
information-flow pattern, provided there is bulk-to-boundary scrambling.
```

## Next Missing Link

The next hard problem is to merge the three pieces:

```text
1. golden-rule energy weights;
2. boundary soft-mode frequencies;
3. microscopic hard/soft information channel.
```

Right now they are separate diagnostics.

The next model should attach energy labels to the hard quanta and let:

```text
p_h(L) ~ rho_bath(omega_h) exp[S(M_L - omega_h) - S(M_L)]
```

inside the same microscopic boundary-emission channel.

That would remove the biggest artificial element in this information-flow test.
