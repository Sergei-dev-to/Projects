# Operator-Overlap Latency Lemma

Date: 2026-07-05

Status: first lemma-level formulation.  The exact result below is a
finite-dimensional visible-algebra obstruction.  The stronger theorem
still to prove is the reduction from a simple instantaneous
`G_D(t)` profile to this visible-algebra quantity for a useful class of
emission models.

## Point of the Lemma

The access-latency paper already proves the geometric version: in a
finite-velocity source-local model, records cannot recover a diary
before the diary light cone reaches the access region.

The memory-burden branch needs the algebraic version:

```text
records may keep flowing,
but if the emitted record algebra has no nontrivial overlap with the
new diary algebra, no decoder can recover the diary coherence.
```

This is the operator-overlap form of the routing-vs-nonlocal-access
fork.  It is deliberately a necessary-condition lemma, not a sufficiency
statement for Hayden-Preskill recovery.

## Model

Work in a finite-dimensional code sector

```text
H_code = H_D tensor H_B,
```

where `D` is the newly deposited diary and `B` is the remaining internal
system in the relevant sector.  Fix a background state `tau_B`.  The
emitted-record channel up to time `T` is

```text
N_T(rho_D)
  = Tr_not_R_T[
      W_T (rho_D tensor tau_B tensor omega_R) W_T^dagger
    ].
```

Let `A_src` be the system-side source algebra through which records are
created.  Let `A_vis(T)` be the algebra of code-sector source operators
that can appear in Heisenberg pullbacks of record observables up to
time `T`.  In a stroboscopic source-local model this is generated by
the coupled algebra at the emission times:

```text
A_vis(T) = Alg{ U(t_j)^dagger A_src U(t_j) : t_j <= T }.
```

For weak or linear-response record formation one may replace the full
algebra by the corresponding linear span to first order.  For exact
multi-record statements, use the full generated algebra.  This
distinction is important: products of many weakly visible operators can
matter even when each single-time overlap is small.

## Diary Visibility

For any code-sector operator `X`, define its diary reduction

```text
Q_D(X) = Tr_B[ (I_D tensor tau_B) X ].
```

The visible algebra is diary-blind when every visible operator reduces
to a scalar on `D`.  Quantify the failure of diary-blindness by

```text
Gamma_D(T)
  = sup_{X in A_vis(T), ||X||_inf <= 1}
      inf_c || Q_D(X) - c I_D ||_inf .
```

Equivalently, `Gamma_D(T)` is the largest expectation difference that a
visible observable can induce between two diary states after the hidden
sector is averaged with `tau_B`.

For a diamond-norm statement, use the completely bounded lift:

```text
Gamma_D^cb(T)
  = sup_A sup_{X in B(A) tensor A_vis(T), ||X||_inf <= 1}
      dist_inf( Q_{AD}(X), B(A) tensor I_D ),
```

where `A` is an arbitrary reference register and `Q_{AD}` traces out
`B` against `tau_B`.  This simply says that even with a reference, the
visible algebra acts only on the reference and not nontrivially on the
diary.

## Lemma: Visible-Algebra Obstruction

Suppose the record channel is source-local through `A_vis(T)`: for every
record observable `M` with `||M||_inf <= 1`, the code-sector
Heisenberg pullback

```text
X_M = P_code W_T^dagger (I tensor M) W_T P_code
```

lies within operator-norm distance `delta_rec` of `A_vis(T)`.  Then
there is a constant diary-independent channel `C_T` such that

```text
|| N_T - C_T ||_diamond
  <= 2 ( Gamma_D^cb(T) + delta_rec ).
```

Consequently, if `Gamma_D^cb(T) + delta_rec = epsilon`, no decoder using
the emitted records up to `T` can achieve order-one diary recovery.  In
entanglement-fidelity language,

```text
F_e <= 1 / d_D^2 + O(epsilon),
```

with the usual translation to average-fidelity conventions.

## Proof

It is enough to work in the Heisenberg picture and use duality of the
trace norm.  Let `M` be a record observable with `||M||_inf <= 1`.  For
two diary states `rho_D` and `sigma_D`, write
`Delta = rho_D - sigma_D`.  Then

```text
Tr[ M ( N_T(rho_D) - N_T(sigma_D) ) ]
  = Tr[ (Delta tensor tau_B) X_M ].
```

Choose `X in A_vis(T)` with `||X_M - X||_inf <= delta_rec`.  The
scalar part of `Q_D(X)` drops out because `Tr Delta = 0`, so

```text
| Tr[ (Delta tensor tau_B) X ] |
  = | Tr_D[ Delta ( Q_D(X) - c I_D ) ] |
  <= ||Delta||_1 Gamma_D(T).
```

The replacement error contributes at most
`||Delta||_1 delta_rec`.  Since `||Delta||_1 <= 2`, the trace-distance
distinguishability of any two diary states in the emitted records is
bounded by

```text
2 ( Gamma_D(T) + delta_rec ).
```

The same argument with an arbitrary diary reference and with the
distance to `B(A) tensor I_D` gives the diamond-norm bound using
`Gamma_D^cb(T)`.

Post-processing cannot increase diamond distance.  A decoder applied to
a diary-independent channel produces a state uncorrelated with the
diary reference, whose overlap with the maximally entangled target is
the no-information baseline.  Therefore a decoder can improve over the
baseline only by the same `O(epsilon)` amount.

## Relation to the Simpler `G_D(t)` Profile

The informal target used the instantaneous routing-overlap profile

```text
G_D(t) = sup_{O in A_D, ||O|| = 1}
         || P_src[ U(t) O U(t)^dagger ] ||.
```

This is the right diagnostic variable, but by itself it is not yet the
theorem.  The exact lemma uses the full visible algebra `A_vis(T)`.
Single-time smallness of `G_D(t)` implies small `Gamma_D(T)` only after
one proves that the record-channel class cannot reconstruct diary
operators from multi-time products whose individual overlaps are small.
This restriction is essential.  In unconstrained bilinear-control or
Lie-algebra-generation settings, repeated conjugations with individually
small overlaps can still generate a large visible algebra.

The tractable bridge class is therefore a fresh-ancilla or
linear-response record model with bounded per-collision strength and a
bounded total record budget.  In that class, the expected reduction is

```text
Gamma_D^cb(T)
  <= C_ch sum_{t_j <= T} g_j G_D(t_j) + O(g^2 T^2),
```

or the corresponding time integral.  For exact stroboscopic record
couplings, or for a persistent outgoing mode sampled many times, replace
the linear sum by the generated-algebra quantity above.  This is the
next technical step if the lemma is promoted into a paper theorem.

## Memory-Burden Application

For the strict Dvali memory-burden prototype, take `A_src` to be the
master-mode emission algebra feeding the `a0 -> b0` line, together with
the diagonal burden-dependent number functions that shift the line.
For fixed diagonal burden sectors:

```text
exchange graph at the flux line:       {a0, b0}
master-memory coupling:                number-number
total memory occupation N_m:           conserved
memory ladder overlap with A_vis(T):   zero
```

Thus `Q_D(X)` is scalar on fixed-sector diary coherences for every
visible master-record operator `X`.  In the strict model,

```text
Gamma_D^cb(T) = 0,
delta_rec = 0,
```

for those coherences.  The emitted record can still carry coarse
diagonal burden tags such as energy or frequency shifts.  That is a
public classical tag, not recovery of an arbitrary new quantum diary
inside a fixed sector.

The black-hole mapping adds rare memory-release channels outside the
strict master-record model.  Dvali 2405.13117 states a model-dependent
post-burden power law `tau ~ R S_BH^(1+k)` with `k > 0`, and gives the
pair-annihilation estimate `tau >= R S_BH^2` as a conservative bound.
Either way this is not HP `R log S`.

The strict prototype is not itself the fresh-ancilla bridge class:
`b0` is a persistent mode, so multi-time products of master quadratures
belong to `A_vis(T)`.  It escapes by exact sector structure instead:
the persistent visible algebra contains diagonal burden tags but no
fixed-sector memory ladder/coherence operator.

This is also the access-cut structure from the Heisenberg-cut/access
notes in concrete form:

```text
diagonal burden data:        public center / classical tag;
fixed-sector coherences:     protected private block;
master-record algebra:       visible cut, with no route into the block.
```

## What Would Make It a Theorem

The lemma becomes the desired theorem after two extra steps:

```text
1. Specify a record-channel class.
   Best first target: sequential fresh-ancilla collisions with bounded
   source-local generators, bounded per-collision strength, and bounded
   total record budget.

2. Bound Gamma_D^cb(T) by a computable routing profile.
   In weak/linear response this should be an integrated G_D(t) bound.
   In exact circuits or persistent-mode records it must use the full
   generated visible algebra.
```

Then the contrapositive is clean:

```text
HP-style order-one recovery by time T
  => Gamma_D^cb(T) = O(1)
     or the emission/access map is not source-local on A_D.
```

This is the intended necessary condition.  It still does not say that
large `Gamma_D` is sufficient for HP recovery; one also needs coherent
export, decoupling, and the usual side-information assumptions.

## Counterexample Routes to Watch

A failed stronger theorem would most likely fail in one of four ways:

```text
1. Nonlocal or constraint-dressed access.
   The record pullbacks are not contained in source-local A_vis(T).

2. Multi-time reconstruction.
   Each instantaneous G_D(t) is small, but products in the generated
   visible algebra reconstruct the diary.  This defeats single-time
   overlap, not the visible-algebra lemma.

   This is the Lie-algebra-generation warning: without a channel-class
   restriction, small one-step overlaps need not prevent controllability
   of the generated algebra.

3. Supplied side information.
   The decoder already holds the diary, its purifier, or an equivalent
   nonlocal encoding.

4. Diagonal tags mistaken for diary recovery.
   Records distinguish public energy/load sectors but not fixed-sector
   quantum coherence.
```

These are not nuisances; they are exactly the branches the program is
trying to separate.

## Current Verdict

At lemma level, the route works.  The exact visible-algebra obstruction
is just data processing plus trace-norm duality, and the strict
memory-burden prototype is its zero-overlap example.

The remaining nontrivial work is not the decoder bound.  It is the
model-dependent bridge from the simple `G_D(t)` routing profile to the
full visible algebra generated by a record channel.
