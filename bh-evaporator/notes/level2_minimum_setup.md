# Level 2: Minimum Microscopic Setup

## Goal

Fix the evidence gap by replacing the synthetic Page curve with an explicit
unitary evaporation simulation generated by one quantum model.

The target is a setup that produces, from the same model:

```text
negative microcanonical heat capacity
accelerating evaporation
thermal-looking early radiation
Page-like entropy turnover
late information recovery / distinguishability growth
```

After the Glatthard/prior-art review, the central requirement is sharper:

```text
the negative-heat-capacity schedule must be generated dynamically by the same
model that produces the radiation entropy curve.
```

It is not enough to attach a Page-like collision model to a hand-labelled
"black-hole-like" system. The energy trajectory, emission probabilities, and
radiation entropy should all be downstream of the shell degeneracies and
transition structure.

The hard version would use one natural local Hamiltonian. The minimum useful
version can be less natural but must be explicit, unitary, and reproducible.

## What counts as "Level 2"?

Level 1:

```text
choose S(E) by hand
choose d_core(E) by hand
apply random isometries
compute Page curve
```

This fixes the synthetic-figure problem but does not give one microscopic
setup.

Level 2 minimum:

```text
define an explicit finite core Hamiltonian H_core
define an explicit radiation-bin Hamiltonian H_rad
define an explicit interaction H_int
evolve the combined pure state unitarily
compute radiation entropy directly
```

The core Hamiltonian may be engineered or random-matrix-like. It does not yet
need to be a simple laboratory Hamiltonian.

Level 2 strong:

```text
use a physically standard Hamiltonian, e.g. Bose-Hubbard / long-range spin /
finite droplet model, whose density of states naturally has a convex intruder
and whose coupling to a waveguide gives the evaporation dynamics.
```

This is much harder.

## Minimum viable microscopic model

Use a shell-resolved chaotic core.

### Core Hilbert space

Let the core have energy shells:

```text
E_0 > E_1 > ... > E_L
```

with shell dimensions:

```text
D_m = round(exp[S(E_m)])
```

Choose an entropy profile with a convex window:

```text
S''(E) > 0
```

and ideally:

```text
S(E) approximately alpha E^2
```

over the working range, so:

```text
T(E) ~ 1/E
C_mu < 0
```

The core Hamiltonian is block diagonal:

```text
H_core = direct sum_m (E_m I_{D_m} + epsilon H_m^{GUE})
```

where `H_m^{GUE}` scrambles within each shell without destroying the coarse
energy structure.

This is not a local Hamiltonian, but it is a bona fide finite quantum system
with a specified density of states and chaotic intra-shell dynamics.

### Radiation bins

Use one fresh radiation bin per emission step. Each bin can be:

```text
qubit: |0>, |1>
or qutrit: |0>, |low>, |high>
or small oscillator truncated to 0/1 occupation
```

Minimum:

```text
one qubit per time bin
```

where `|1>` means an emitted quantum and `|0>` means no emission.

For black-hole-like energy loss, a qutrit or small set of frequencies is
better:

```text
|0>, |omega_1>, |omega_2>, ...
```

### Interaction

At step `m`, couple the current core shell to the next lower shell and the next
radiation bin:

```text
H_int^{(m)}
  =
  g_m X_m tensor |1><0|_rad
  + h.c.
```

where:

```text
X_m: H_core(E_m) -> H_core(E_{m+1})
```

is a random matrix normalized so that Golden-rule rates follow the desired
emission schedule.

A collision step is:

```text
U_m = exp[-i Delta_t (H_core + H_rad,m + H_int^{(m)})]
```

acting only on:

```text
core + fresh radiation bin
```

After the step, the bin is never coupled again. This mimics a chiral waveguide
or outgoing time-bin field and prevents reabsorption.

This is a sequence of microscopic unitary interactions. It is not a single
time-independent Hamiltonian, but it is experimentally standard as a collision
model/time-bin model.

## Why this is enough

This model has:

```text
explicit H_core
explicit H_int
explicit pure-state unitary evolution
explicit radiation degrees of freedom
direct computation of S2_rad(t)
direct distinguishability / recovery tests
```

It also keeps the thermodynamic schedule tied to the same shell structure:

```text
D_m -> S(E_m) -> T(E_m) -> emission rates -> energy trajectory
```

This is a real upgrade over hand-drawing a Page curve.

## Pass/fail criterion

The minimum dynamic test succeeds only if the simulation produces all of the
following from one specified model:

```text
1. S(E) with a convex window, so beta(E) decreases as energy decreases.
2. An energy trajectory E(t) whose loss rate increases during evaporation.
3. Emission probabilities/rates derived from shell dimensions and couplings,
   not independently drawn to look black-hole-like.
4. Radiation entropy computed from the emitted time bins, not inserted by a
   Page-curve ansatz.
5. A Page-time estimate that tracks the Hilbert-space competition between
   emitted radiation and the remaining core.
```

Failure modes:

```text
If the entropy curve is produced by random isometries but the evaporation
schedule is imposed separately, this is only Level 1.5.

If the model is just an excited system relaxing into a cold bath, this is too
close to existing open-system Page-curve work.

If negative heat capacity only appears in a plot of S(E) and does not control
emission, it is cosmetic.
```

## What it still does not prove

It does not prove:

```text
a natural local many-body Hamiltonian has the full behavior
the old XXZ core alone generates a Page curve
the model is experimentally immediate
```

It is an engineered microscopic evaporator.

That is acceptable if the paper is framed as:

```text
a minimal geometry-free quantum evaporator
```

not:

```text
an emergent black hole from a natural condensed-matter Hamiltonian
```

## Simulation feasibility

Exact state-vector simulation grows as:

```text
dim_total = D_core_remaining * 2^n_rad
```

Naively this explodes. But the collision/isometry structure can be represented
as a matrix product state or as an explicit state over:

```text
current core shell x emitted bins
```

For a first brute-force version, keep dimensions small:

```text
L = 10-16 shells
D_max = 64-512
n_rad = L
rad_dim = 2
```

Total vector size at Page time can be kept below:

```text
~ 10^5 to 10^6 amplitudes
```

which is feasible in NumPy/SciPy.

The first implementation should use shell-wise isometries directly:

```text
V_m: C^{D_m} -> C^{D_{m+1}} tensor C^{r}
```

where `V_m` is generated from QR decomposition of a random complex matrix.

This is Level 1.5 / Level 2-minimum:

```text
explicit shell model and unitary isometries
not yet Hamiltonian exponentials
```

Then upgrade to Hamiltonian collision steps if needed.

## Minimum outputs

The simulation should produce:

```text
1. S(E_m) and T(E_m), showing C_mu < 0.
2. Mean core energy E(t), showing accelerating evaporation.
3. Radiation Renyi-2 entropy S2_rad(t), computed from the state.
4. Page-time estimate from dim H_rad ~ dim H_core.
5. Distinguishability between two initial core states as seen in radiation.
6. Optional recovery fidelity using a simple decoder or Petz-style map.
```

## Stronger physical variant

After the shell model works, try a physical core:

```text
finite Bose-Hubbard cluster with attractive/long-range interactions
long-range spin model with phase-coexistence DOS
finite cluster/droplet model with known convex intruder
```

Couple it to outgoing time-bin modes:

```text
H_int = sum_t g(t) X tensor b_t^\dagger + h.c.
```

This would be closer to a laboratory proposal but is not necessary for the
first credible paper.

## Recommendation

Do not jump directly to a natural local Hamiltonian.

Proceed in three steps:

```text
Step 1:
  shell-isometry evaporator with explicit S(E), compute actual Page curve.

Step 2:
  replace direct isometries with collision Hamiltonians that generate the
  same emission maps.

Step 3:
  search for a physical core Hamiltonian whose DOS supplies the shell
  dimensions naturally.
```

Step 1 is enough to remove the current synthetic Page-curve weakness. Step 2 is
enough to claim an explicit unitary microscopic setup. Step 3 is a future
upgrade.

Revised recommendation after the prior-art check:

```text
Run Step 1.5/2 as a kill test.

The project is worth continuing only if the negative-C_mu schedule and the
Page-like information-flow diagnostics come from the same evaporation map.
```

The first implementation can still use shell isometries, but the probabilities
for staying/emitting/transitioning must be tied to:

```text
D_m = exp[S(E_m)]
beta_m = dS/dE
available final-state multiplicities
chosen passband / transition matrix elements
```

That is the minimum version that is meaningfully different from generic
Page-curve-without-gravity models.
