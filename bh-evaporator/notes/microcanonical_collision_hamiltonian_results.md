# Microcanonical Collision Hamiltonian Results

## Purpose

Turn the hard/soft erosion channel into an explicit collision Hamiltonian and
use hard weights derived from microcanonical state counting.

This addresses the previous weak point:

```text
the erosion channel was declared as a Stinespring map.
```

The new construction uses:

```text
H_coll = g (V + V^\dagger),
```

where `V` is an isometry from the shell Hilbert space to:

```text
H_hard tensor H_soft.
```

The hard probabilities are:

```text
p_h(L) ~ integral over hard bin h of
         rho_2D(omega) exp[S(M_L - omega) - S(M_L)].
```

So the hard spectrum is tied to the droplet entropy curve, not chosen as a
thermal distribution.

## Collision Hamiltonian

Let the shell dimension be:

```text
D_shell = q^(2L - 1).
```

Define an isometry:

```text
V: H_shell -> H_hard tensor H_soft
```

with:

```text
dim H_soft = dim H_shell.
```

The script tests two structured choices:

```text
shift:
  U_h is a cyclic shift on shell labels.

clock:
  U_h is a diagonal clock phase on shell labels.
```

The emitted state is:

```text
V |psi> = sum_h sqrt(p_h) |h>_hard U_h |psi>_soft.
```

Then:

```text
H_coll = g (V + V^\dagger).
```

On an input shell state:

```text
exp(-i theta H_coll) |in, psi>
  = cos(theta) |in, psi> - i sin(theta) |out, V psi>.
```

At short time:

```text
P_h ~ theta^2 p_h.
```

At:

```text
theta = pi/2
```

the shell is fully transferred to hard+soft radiation. The multi-shell
diagnostic uses this complete collision pulse to model one erosion step.

The script explicitly builds the single-shell Hamiltonian matrix for a small
check and compares dense exponentiation with the analytic formula:

```text
single-shell Hamiltonian formula error: 1.433e-16
```

So the Stinespring map is genuinely generated by a finite Hamiltonian block.

## Result

The collision Hamiltonian reproduces the hard/soft pattern using
microcanonical hard weights.

Representative summary:

```text
model L  D_hard  S_h/target  I_hh    I_pair
clock 2  0.0021  1.232/1.233  0.0001   2.679
clock 3  0.0028  1.292/1.292  0.0001   5.415
clock 4  0.0027  1.303/1.303  0.0000   0.000

shift 2  0.0026  1.232/1.233  0.0001   2.679
shift 3  0.0028  1.292/1.292  0.0001   5.415
shift 4  0.0022  1.303/1.303  0.0000   0.000
```

Here:

```text
D_hard:
  trace distance between latest hard marginal and target microcanonical hard
  distribution.

S_h/target:
  latest hard entropy compared with target hard-bin entropy.

I_hh:
  mutual information between first and latest hard bins.

I_pair:
  mutual information between first and latest hard+soft emitted pairs.
```

The `L = 4` row has `I_pair = 0` because it is the first emission step in an
`L0 = 4` run. The later rows show the early/late pair correlations.

The hard-only early/late mutual information remains near zero, while hard+soft
pair mutual information is nonzero after multiple emissions.

## Hard Weights

The hard-bin probabilities change with `L`, because they are recomputed from:

```text
rho_2D(omega) exp[S(M_L - omega) - S(M_L)].
```

For `d_hard = 4`, the first bins are approximately:

```text
L = 4:
  0.0931, 0.2939, 0.3343, ...

L = 3:
  0.0840, 0.2741, 0.3336, ...

L = 2:
  0.0604, 0.2171, 0.3217, ...
```

This is not the earlier hand-chosen:

```text
p_h ~ exp(-h).
```

It is a discretized 2D bath spectrum multiplied by the exact finite-size
microcanonical entropy ratio.

## What This Fixes

This is the first version where the erosion step has all three:

```text
1. finite Hamiltonian generation;
2. minimal hard+soft radiation output;
3. entropy-derived hard weights.
```

It upgrades the channel story from:

```text
declared Stinespring map with chosen thermal probabilities
```

to:

```text
collision Hamiltonian whose short-time branch weights are the microcanonical
emission rates.
```

## What It Still Does Not Fix

This is still not the final autonomous evaporator.

Remaining caveats:

```text
1. H_coll is a collision Hamiltonian for one shell, not one global Hamiltonian
   containing every L sector at once.

2. The complete erosion step uses a pi/2 pulse. The weak-coupling interpretation
   is in the short-time branch weights, while the full pulse is a coarse-grained
   shell-transfer model.

3. The matrix elements are smooth by construction. We derive the entropy/bath
   weights, but not greybody factors or boundary selection rules.

4. The soft record is the minimal shell-sized record, but its microscopic bath
   carrier is still abstract.

5. The scrambling Hamiltonian and collision Hamiltonian are not yet combined
   into one continuous-time evolution.

6. The droplet formation and boundary line tension are still external model
   ingredients.
```
