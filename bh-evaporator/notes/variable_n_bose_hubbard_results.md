# Variable-N Bose-Hubbard Evaporation Probe

## Motivation

The fixed-particle Bose-Hubbard emission test was conceptually mismatched to
black-hole evaporation. It allowed relaxation inside one fixed Hilbert-space
sector:

```text
H_N -> H_N
```

but a black hole shrinks:

```text
mass decreases
area decreases
entropy decreases
temperature increases
```

The closer Bose-Hubbard analogue is particle loss:

```text
H_N -> H_{N-1}
```

generated by annihilation operators:

```text
b_i : H_N -> H_{N-1}
```


Data:

```text

```

Core:

```text
H_core = direct sum_N H_N
N = 8, 7, 6, 5, 4, 3
```

Each sector is a six-site attractive Bose-Hubbard ring:

```text
J = 0.5
U = -1
V_nn = -0.2
```

Sector dimensions:

```text
N=8: 1287
N=7: 792
N=6: 462
N=5: 252
N=4: 126
N=3: 56
```

So the internal Hilbert space genuinely shrinks as the object evaporates.

The total energy uses a particle-number offset:

```text
E_total(N, alpha) = mu N + epsilon_alpha^(N)
```

where `epsilon_alpha^(N)` is the Bose-Hubbard eigenvalue in sector `N`. The
offset is the mass/chemical-potential bookkeeping needed to make particle loss
carry positive energy.

Transition rates:

```text
Gamma_{N,alpha -> N-1,beta}
  proportional to sum_i |<beta,N-1| b_i |alpha,N>|^2 J(omega)

omega = E_total(N,alpha) - E_total(N-1,beta)
```

Only positive emitted gaps in a specified window are kept.

The evolution is a weak-coupling population Markov map. This is still not the
full unitary collision model.

## Interpretation

This is the first Step 3 result that actually moves in the right direction.

The fixed-N result taught:

```text
convex DOS alone is not sufficient.
```

The variable-N result adds:

```text
shrinking Hilbert-space sectors plus physical particle-loss operators can
recover accelerating emission in a natural many-body model.
```

That is much closer to black-hole evaporation than internal fixed-sector
relaxation.

## Caveats

This is not yet the final result.

Important caveats:

```text
1. The calculation is a weak-coupling population Markov diagnostic, not a
   unitary collision-Hamiltonian simulation.

2. The mass/chemical-potential offset mu is scanned. This is physically
   interpretable, but still a tunable bookkeeping parameter.

3. The result shows accelerating emitted power, but not yet a Page curve.

4. The radiation Hilbert space is not explicitly tracked in this test.

5. We have not yet checked finite-size robustness beyond the L=6, N<=8
   Bose-Hubbard ring.
```

## Current verdict

The variable-N Bose-Hubbard model is now the leading natural-core candidate.

It is not a replacement for the engineered shell paper yet, but it is no
longer just future speculation. It gives a concrete path:

```text
1. natural shrinking Hilbert space;
2. physical particle-loss emission operators;
3. accelerating evaporation over a working window.
```

The next test should be a reduced-density collision model for the same
variable-N sectors. If that works, Step 3 becomes a serious extension rather
than a side note.

This model is now classified as Track A:

quantum dynamics. It is not the entropy-scaling model, because fixed-site

```text
dim H_N = binomial(N + L - 1, N)
```

which does not give:

