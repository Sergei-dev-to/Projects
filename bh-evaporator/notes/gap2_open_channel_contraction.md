# Gap 2: Open-Channel Contraction

## Purpose

The previous two-replica note phrased the deterministic gap too close to a
closed-system Hamiltonian gap.  A fixed unitary evolution

```tex
\rho\mapsto U(t)\rho U(t)^\dagger
```

preserves Hilbert-Schmidt distances.  Its two-copy representation has spectrum
on the unit circle.  It cannot, by itself, be the object that contracts
reference correlations.

The contracting object must be the coarse weak-emission block: in-shell
Hamiltonian evolution, followed by weak emission, with the emitted mode either
recorded as radiation or traced from the remaining core.

## One Emission Block

In one shell, let

```tex
U_j(t)=e^{-iK_j t}
```

be the in-shell mixing evolution.  Let the weak emission jump labels be

```tex
\alpha=(\omega,\lambda,\mu),
```

with jump operators

```tex
L_{\alpha,j}:\mathcal H_j\to \mathcal H_{j+1,\alpha}.
```

Conditioned on an emission during a coarse block, the physical Kraus operators
have the schematic form

```tex
M_{\alpha,t}=c_{\alpha,t}\,L_{\alpha,j}U_j(t),
```

where `c_{\alpha,t}` includes the waiting-time density and the normalization by
the total emission probability in the block.  If the waiting time is resolved,
`t` is part of the radiation record; if it is unresolved, it is averaged.

The Stinespring map for the block is

```tex
V_j|\psi\rangle
=
\sum_\alpha\int dt\,
M_{\alpha,t}|\psi\rangle\otimes|\alpha,t\rangle_R .
```

The remaining-core channel is

```tex
\Phi_j^B(\rho)
=
\sum_\alpha\int dt\,
M_{\alpha,t}\rho M_{\alpha,t}^\dagger .
```

The radiation-including channel is

```tex
\Phi_j^{BR}(\rho)
=
\sum_{\alpha,\beta}\int dt\,dt'\,
M_{\alpha,t}\rho M_{\beta,t'}^\dagger
\otimes|\alpha,t\rangle\langle\beta,t'|_R
```

when the radiation record is kept coherently.  If the emission time/channel is
decohered by the outgoing continuum, the off-diagonal record terms are absent.
The draft currently uses the Markov/quantum-jump version, so the natural
calculation is the Kraus-channel one.

## The Two-Copy Maps

For remaining-core purity, the relevant two-copy superoperator is

```tex
\Phi_j^{B,(2)}(X)
=
\sum_{\alpha,\beta}\int dt\,dt'\,
(M_{\alpha,t}\otimes M_{\beta,t'})
X
(M_{\alpha,t}^\dagger\otimes M_{\beta,t'}^\dagger).
```

For the purity of the fine radiation-recorded channel, orthogonal jump records
select equal labels in the collision term:

```tex
\Phi_j^{R{\rm rec},(2)}(X)
=
\sum_{\alpha}\int dt\,
(M_{\alpha,t}\otimes M_{\alpha,t})
X
(M_{\alpha,t}^\dagger\otimes M_{\alpha,t}^\dagger),
```

with the obvious modification if the time record is coherent rather than
classical.  These are the actual two-replica objects relevant to the Page
diagnostics.  They contain `K_j`, but they are not the same as
`U_j(t)^{\otimes2}`.

## What Contracts

Let `Q` purify the initial code state.  The post-Page diagnostic is

```tex
\Delta_j^{(2)}
=
\|\rho_{QB_j}-\rho_Q\otimes\rho_{B_j}\|_2^2 .
```

The useful estimate is

```tex
\Delta_{j+1}^{(2)}
\le
\kappa_j\Delta_j^{(2)}
\varepsilon_j ,
\qquad
\kappa_j<1 .
```

The contraction is produced by the open block:

```text
Hamiltonian mixing spreads the code information across the shell.
The emission Kraus operators remove/sample boundary degrees.
Tracing or recording the outgoing mode changes the accessible subsystem.
```

In the ideal Haar block, the contraction factor is controlled by the dimension
ratio between the remaining core and the pre-emission core, with the usual
code-size correction.  For a deterministic Hamiltonian, the error
`\varepsilon_j` measures how far the actual open-block second moment is from
that ideal second moment.

## Literature Translation

The random-circuit literature obtains a second-moment Markov operator by
averaging over random gates.  The open-channel formulation gives an analogous
object without inventing gate randomness: the completely positive block map is
generated by standard weak-coupling emission.

Existing tools now become relevant in a more precise way.

```text
Open quantum systems:
    weak-coupling/Markov theory supplies the Kraus or Lindblad block.

Random-circuit decoupling:
    supplies the comparison target for second moments.

Quantum Perron-Frobenius / primitive-channel theory:
    supplies criteria for eventual mixing of a completely positive map.

Quantum log-Sobolev / rapid-mixing theory:
    supplies the type of estimate needed for scaling, if the block channel can
    be placed in one of those known classes.
```

The primitive-channel route is useful but not sufficient by itself.  Quantum
Wielandt-type results show eventual full-rank mixing under irreducibility
conditions, but their general bounds are far too weak for fast scrambling.  To
match black-hole phenomenology one needs a gap or log-Sobolev estimate strong
enough to give mixing on the `O(log N)` scale, or at least fast enough compared
with the mean emission time.

There is also a structural mismatch.  Primitive-channel and log-Sobolev
theorems usually apply to repeated evolution on one fixed operator algebra:

```tex
\Phi:\mathcal B(\mathcal H)\to\mathcal B(\mathcal H).
```

One evaporation block is a shrinking channel:

```tex
\Phi_j:\mathcal B(\mathcal H_j)\to
\mathcal B(\mathcal H_{j+1}),
\qquad
\dim\mathcal H_{j+1}<\dim\mathcal H_j .
```

Thus the relevant estimate is not convergence of `\Phi^m` to a fixed point.
It is a one-step or cumulative decoupling estimate for a sequence of maps
between different shells:

```tex
\Phi_{m-1}\cdots\Phi_1\Phi_0:
\mathcal B(\mathcal H_0)\to\mathcal B(\mathcal H_m).
```

The fixed-algebra theory is still useful as a template for what a two-copy
gap means, but the actual evaporator needs a shrinking-channel analogue.

## A More Concrete Bound To Aim For

Let `\mathcal C_j` be the transported code subspace in shell `j`, purified by
`Q`, and let

```tex
\Phi_j^B:\mathcal B(\mathcal H_j)\to\mathcal B(\mathcal H_{j+1})
```

be the remaining-core channel for one conditioned emission block.  Define the
centered correlation operator

```tex
X_j=\rho_{QB_j}-\rho_Q\otimes\rho_{B_j}.
```

The required estimate can be phrased as a norm bound on centered operators:

```tex
\|(I_Q\otimes\Phi_j^B)(X_j)\|_2^2
\le
\kappa_j\|X_j\|_2^2+\varepsilon_j .
```

This is the channel form of post-Page decoupling.  The pre-Page version uses
the radiation-record channel in place of `\Phi_j^B`.

For an ideal Haar-scrambled boundary emission block, `\kappa_j` is controlled
by the fraction of the shell dimension left behind after the emission, with
the usual finite-code correction.  For the deterministic Cayley candidate, the
same inequality is the target theorem.

Equivalently, one can state the target in Choi form.  Let `J(\Phi_j^B)` be the
Choi operator of the remaining-core channel, projected to a fixed charge
sector.  The bound asks that this Choi state be close, in its second moment on
the code sector, to the Choi state of the Haar-scrambled shrinking channel.
That form aligns directly with decoupling theorems and avoids discussing a
nonexistent fixed-point gap for a dimension-changing map.

## Revised Remaining Gap

The deterministic sparse-Hamiltonian gap is now:

```text
For the weak-emission block generated by a fixed homogeneous Cayley-expander
Hamiltonian K_j and symmetry-related boundary jump operators L_alpha,j, prove
that the induced two-copy open-channel map contracts non-charge reference
correlations inside each symmetry sector, with a rate fast enough that
t_scr << t_emit over the semiclassical evaporation window.
```

An equivalent decoupling-theorem formulation is:

```text
the Choi state of the physical shrinking channel is second-moment close, on
the code sector and within fixed charge sectors, to the Choi state of the
ideal Haar-scrambled shrinking isometry.
```

This is narrower than proving that `K_j` is a unitary design.  It is also more
honest than assigning a dissipative gap to closed Hamiltonian evolution.

## Consequences For The Paper

The paper should phrase the deterministic-candidate paragraph around the
two-replica weak-emission block, not around a spectral gap of `K_j` alone.

The current analytical result remains intact:

```text
If the shell-mixing/input decoupling condition holds, the black-hole
evaporation phenomenology follows.
```

The stronger deterministic program becomes:

```text
replace the abstract mixing input by a primitive/rapidly mixing open channel
generated by a fixed sparse Hamiltonian plus the same weak emission operators.
```

The more explicit ETH version of this bridge is in
`notes/weak_emission_eth_bridge.md`.  There the one-step remaining-core and
complementary radiation channels are written out, and the common
second-moment object is the emission-image overlap kernel

```tex
G_{\nu\nu'}=
\operatorname{Tr}[\rho'(\nu)\rho'(\nu')].
```

## Current Assessment

This is progress.  It removes a false target and replaces it with a standard
open-system object.  It does not close Gap 2 completely.  The new best route is
to look for, or prove, a rapid-mixing estimate for the two-copy weak-emission
channel rather than for the closed unitary dynamics alone.
