# Integrated Microcanonical Coded Pump

Date: 2026-07-10

Status: exact time-homogeneous repeated-collision isometry combining a finite
shrinking `S(E)~E^2` shell, density-of-states thermal emission odds, explicit
event partners, and a locally identical multi-time diary code. This closes the
abstract integration gap between the finite pump and shrinking-shell controls.
It is not yet generated by a simple time-independent Hamiltonian and is not a
bosonic greybody model.

## 1. Shrinking Microcanonical Memory

Let

```text
H_BH = direct_sum_(j=0)^L |j> tensor H_j,
dim H_j = d_j = 2^(L-j),
S_j = S_res + log d_j,
E_j = sqrt(S_j/alpha).                                    (1.1)
```

Then `S_j=alpha E_j^2` exactly. Put

```text
omega_j = E_j-E_(j+1),
x_j = d_(j+1)/d_j = exp(S_(j+1)-S_j)
    = exp(-beta_j omega_j) = 1/2,
p_j = x_j/(1+x_j) = 1/3.                                 (1.2)
```

The shell label `j` is the finite pump level. A successful emission lowers the
energy from `E_j` to `E_(j+1)` and removes one entropy qubit. A no-emission
collision leaves the shell unchanged.

## 2. One Time-Homogeneous Collision Rule

For each shell choose an isometry

```text
J_j : H_j -> H_(j+1) tensor C_j,                          (2.1)
```

which exists exactly because `dim C_j=2=d_j/d_(j+1)`. The outgoing wave packet
contains an energy/event label `h_j` and degeneracy label `C_j`; an inaccessible
event partner is `b_j`. A diary-independent purifier `T_j` prepares the
degeneracy label on no-emission attempts.

On fresh vacuum records define one direct-sum isometry `V_mix` by

```text
V_mix |j,psi>|vac>
 = sqrt(1-p_j) |j,psi>|0>_h|0>_b |Phi>_(C T)
 + sqrt(p_j) |j+1> J_j|psi> |1>_h|1>_b |0>_T.            (2.2)
```

The two branches are orthogonal, so (2.2) is normalized. The same operator is
reused at every collision; the current shell block selects `p_j,J_j`. Every
isometry has a unitary extension on the system plus a sufficiently large fresh
ancilla.

Here `|Phi>_(CT)` is a Bell pair. On the diary code used below, the successful
`C` factor is also exactly maximally mixed. Consequently the complete
one-collision exterior state is literally

```text
rho_(hC) = diag(1-p_j,p_j)_h tensor I_C/2,                (2.3)
```

in both the blind and mixing branches. The exterior event odds are exactly

```text
Pr(h=1)/Pr(h=0) = p_j/(1-p_j)
                 = exp(-beta_j omega_j),                 (2.4)
```

and shell energy decreases only on the event branch. After a no-emission event
the collision may be retried. For constant `p=1/3`, the number of collisions to
obtain `L` emissions is negative binomial with

```text
mean collisions = L/p = 3L,
variance = L(1-p)/p^2 = 6L.                              (2.5)
```

The pump is finite: after `L` successful events it reaches the residual shell.

## 3. Blind Comparison Collision

For the blind branch replace `J_j` by

```text
J_j^P : H_j -> H_(j+1) tensor P_j,                       (3.1)
```

route the removed logical qubit to hidden `P_j`, and emit the same fixed
maximally mixed degeneracy label `C_j` purified by hidden `T_j` on both event
branches.
Conditional on the same event record, the exterior state is independent of the
diary. The information-carrying archive dimension grows by the required factor
`d_j/d_(j+1)=2` per successful event, saturating the no-hiding archive bound.

The local/event statistics (2.3)--(2.4), shell trajectory, and event-partner record
are exactly the same as in the mixing branch.

## 4. Correlation-Only Mixing Branch

For `L=5`, choose the initial diary code to be the perfect `[[5,1,3]]` code and
let the `J_j` successively expose its five physical degeneracy factors. Then,
conditional on successful emission,

```text
rho_(C_j) = I_2/2                                         (4.1)
```

for every diary state and every `j`. The blind and mixing branches therefore

```text

event odds:       p/(1-p)=1/2;
```

Nevertheless the records differ globally:


No-emission records reveal only waiting time and do not change these code

## 5. Q2 Evaluation

The blind construction is an exact diary-blind comparison comb. The mixing
construction has order-one process distance from it on the successful routing
steps and reaches exact recovery after the third successful code emission.
This is consistent with the composable converse:

```text
accurate recovery requires order-one cumulative distance from the blind comb.
```

The construction also shows why the converse cannot be strengthened to
sufficiency using only the scalar cumulative distance. A weak or anisotropic
route can have order-one total defect while exposing only a charge or an
uncorrectable subset. Sufficiency needs a directional condition such as
decoupling, a temporal design, or an ETH second-moment statement.

## 6. What Is Now Genuinely Open

The remaining gap is no longer an abstract channel construction. It is to
derive a comparable process from constrained dynamics:

1. Find a simple time-independent Hamiltonian whose scattering/collision
   dynamics approximates (2.2), including greybody propagation and the
   changing `omega_j`.
2. Replace the supplied stabilizer encoder by a natural temporal mixer and
   prove a uniform decoupling/design or ETH condition along the shrinking
   trajectory.
3. Identify the physical exterior algebra and partner disposition in a named
   microscopic gravity model.

A universal circuit-to-Hamiltonian clock could realize the isometry but would
only hide the supplied encoder in the Hamiltonian. It would not answer the
demarcation question. Progress now requires either a physically motivated
Hamiltonian family or contact with a microscopic gravity model.
