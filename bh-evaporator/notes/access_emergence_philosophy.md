# Access, emergence, and substrate independence

Date: 2026-06-13

Status: speculative implications note.  This is not part of the
technical claim stack unless the constrained-access diagnostics become
formal.

Role in the notes:

```text
This file is the speculative implications and emergence/locality note.
`constrained_access_channel.md` holds the technical taxonomy.

```

## Prompt

The constrained-access channel may have philosophical implications for
emergence, especially Everett/decoherence/Quantum-Darwinism-style
accounts, and for substrate independence.

The technical seed is:

```text
Information existing in the global quantum state is not the same as
information being accessible to a specified observer algebra, in
redundant records, within a latency and complexity budget.
```

## 1. Emergence needs an access clause

A common strong emergence story says: if the global quantum state
contains stable patterns and evolves unitarily, the higher-level
ontology follows.

The access-channel view suggests a stricter condition:

```text
Emergent facts are patterns that are stably and redundantly accessible
to the relevant observer algebras.
```

Quantum Darwinism already points this way: decoherence alone is not the
whole story; objective classicality comes from redundant environmental
records of selected pointer observables.

The horizon case sharpens it:

- no-hair data are redundantly accessible;
- microscopic diary/microstate data may be globally present but
  inaccessible to small fragments, delayed until Page/HP conditions, or
  hidden behind high decoding complexity;
- changing the access algebra changes what can operationally emerge.

So "pattern exists" is not enough.  The pattern must be accessible in
the right way.

## 2. Horizons as physical Heisenberg cuts

The ordinary Heisenberg cut separates system from apparatus/record.  In
measurement theory its placement is partly conventional: include more
apparatus quantum-mechanically and the cut moves.

Horizons make cut movement physical.  The cut shifts only when the
access algebra changes:

- collecting old radiation changes the Page/Hayden-Preskill access
  algebra;
- islands change the reconstruction algebra;
- mining changes the exterior coupling algebra;
- boundary CFT reconstruction changes the observer algebra;
- Gauss-law dressing may make the naive cut nonfactorizing from the
  start.

Candidate philosophical statement:

> A finite horizon is a thermodynamic Heisenberg cut: no-hair data are
> pointer observables, while microscopic quantum data remain accessible
> only through large, delayed, nonlocal, or high-complexity records.

This is not a collapse claim.  It is a claim about operational access.

## 3. Objectivity versus recoverability

Quantum Darwinism links objectivity to redundant records.  The horizon
channel separates objectivity from unitarity:

```text
classical/no-hair data -> redundantly broadcast -> objective;
fine quantum data      -> globally encoded       -> recoverable only
                                           from large/hard algebras.
```

Thus black-hole radiation is Darwinian at the classical level and
cryptographic at the microscopic level.

This distinction may matter for Everettian emergence.  Branch
structure/objectivity tracks redundant records; global unitarity tracks
recoverability in much larger algebras.  These are different
properties.

## 4. Substrate independence has an access condition

If two systems compute the same abstract input-output map but differ in
their access algebras, record redundancy, latency, and decoding
complexity, they may not realize the same emergent world for embedded
or exterior observers.

Examples:

- ordinary reservoir versus black-hole horizon: same coarse thermality
  can coexist with different recovery latency;
- tape emitter versus scrambler: same eventual unitary release, different
  access curve for arbitrary new deposits;
- factorized HP model versus Gauss-law gravity: different exterior
  algebra even if both preserve information;
- simulation with full state access versus physical horizon with
  passive Hawking access: same formal state evolution, different
  observer-access structure.

Candidate statement:

> Substrate independence is constrained by access structure.  A
> substrate does not realize the same emergent physics unless it
> reproduces the relevant records, redundancies, latencies, and
> complexity barriers for the observers in question.

This is not anti-physicalist.  It is a stronger physicalism: emergence
depends on physical access channels, not only abstract state patterns.

## 5. Carroll-style emergence pressure point

For Sean-Carroll-style Everettian/pattern emergence, the access-channel
critique should be framed narrowly:

```text
Global wavefunction patterns are insufficient unless the theory also
specifies which records are accessible, redundant, and stable for which
observers.
```

The black-hole information problem is a stress test because it separates
the following:

- global unitarity;
- coarse classical objectivity;
- fine-grained recoverability;
- observer-dependent access;
- computational feasibility.

These are often rhetorically compressed into "the information is in the
wavefunction" or "the pattern emerges."  Horizons show that those are
not the same operational claim.

## 6. Technical guardrails

This implication note should not become free-floating philosophy.  The
only defensible bridge is through measurable/formal access diagnostics:

- distinguishability over an observer algebra;
- recoverability fidelity;
- participation number of the access algebra;
- Darwinian redundancy of records;
- latency;
- decoding complexity.

Without those diagnostics, the Heisenberg-cut and substrate-
independence language is only metaphor.

## 7. Possible concise thesis

> Emergence is not merely stable patterns in the universal state.
> Emergence is stable patterns made available through constrained access
> channels.  Horizons expose this because they redundantly broadcast
> classical no-hair data while hiding microscopic quantum data in
> delayed, nonlocal, or high-complexity records.

## 8. Quarantined north star: gravity as pointer sector

Status: speculative.  Not a claim, not part of the technical stack, and
not worth pursuing unless it produces diagnostics tied to redundancy,
constraints, latency, or complexity.

Possible north star:

> Classical gravitational geometry may be the public pointer sector
> selected by universal coupling and constraint-dressed access.
> No-hair data, ADM/BMS charges, horizon area, and coarse causal
> structure are redundantly recordable; microscopic quantum information
> remains nonredundant and globally encoded.  In this view, gravity is
> not classical because quantization failed, but because it is the
> robust access layer of an underlying quantum system.

This would connect the constrained-access program to a broader
emergence idea: geometry as the redundantly accessible record structure
of quantum degrees of freedom.  It is only useful if it can be made to
touch concrete quantities such as Darwinian redundancy of gravitational
charges, distinguishability of dressed observables, or access latency
for non-pointer information.

## 9. What "gravity emerges" could mean

The phrase is too broad unless split into levels.  For this program,
"gravity" should not be treated as one target.

### G1. Public gravitational data

The weakest and most accessible meaning:

```text
mass, energy, momentum, angular momentum, charges, horizon area,
coarse causal relations, and other long-range/classical data are
redundantly accessible to many observer algebras.
```

This is gravity as public pointer structure.  It is the level closest to
the Darwinian/no-hair theorem: the center of the access algebra becomes
classical because it is redundantly recorded.

Diagnostic:

```text
redundancy and distinguishability of gravitational/no-hair observables
across many fragments or asymptotic records.
```

### G2. Constraint/dressing structure

The next meaning:

```text
local subsystems fail to factor naively because physical observables are
constraint-dressed and tied to boundary/asymptotic data.
```

This is the Gauss-law/Raju/holography-of-information layer.  In access
language, gravity changes the available algebra `A(t)`, not merely the
state inside a fixed factorization.

Diagnostic:

```text
distinguishability over dressed/asymptotic observables for states that
would be identical under a factorized exterior algebra, with latency and
complexity budgets included.
```

### G3. Horizon access profile

The horizon-specific meaning:

```text
a finite sector has public no-hair center, private microscopic blocks,
compressed anonymous passive records, and saturated low-latency
recovery from enlarged/delayed access.
```

This is where the operational-horizon, boundary-saturation, and
Darwinian/no-hair results meet.

Diagnostic:

```text
center-public + block-private + anonymous/compressed record
+ saturated Page/HP latency.
```

### G4. Effective spacetime dynamics

The strongest meaning:

```text
an effective metric, causal structure, and dynamical equations such as
Einstein-like response emerge from the same underlying access structure.
```

This is not yet reached by the current results.  The access program may
provide candidate public variables and constraints, but it has not
derived a local metric dynamics.

Diagnostic would have to include:

```text
effective causal cones, equivalence-principle-like universal coupling,
linearized gravitational response, and eventually nonlinear dynamics.
```

## 10. Working aspiration

The ambitious reading is not "gravity is unnecessary."  It is:

> Many gravity-like operational features may be consequences of a
> constrained access structure: public centers, private blocks,
> anonymous compressed records, and constrained/dressed observer
> algebras.  Classical gravity would then be the public, redundantly
> accessible access layer of a deeper quantum system.

Under this reading, the current program is probing G1--G3.  G4 remains
the ceiling, not an achieved result.

Sharper aspirational target:

> Horizon behavior may be a constrained-access universality class.

This means the operational horizon package is defined by public
commuting data, private quantum blocks, anonymous/compressed passive
records, source-side saturation, delayed or dressed recovery, and a
latency/complexity law.  This target concerns operational horizon
behavior.  It does not by itself derive metric dynamics, Lorentzian
geometry, or Einstein-like response.

## 11. Geometry above the cut

Sharper target than "geometry emerges in general":

> Geometry above the cut is the relational structure represented in
> public, stable, observer-accessible records.

Here "above the cut" means the classical/operational layer available to
specified observer algebras, not the fundamental microscopic substrate.
The program is not to recover geometry from the whole quantum state, but
to ask whether the records that become public define an effective
geometry for observers.

Proposed dictionary:

```text
events:
    stable public records / central projections;

spatial proximity:
    redundancy overlap, mutual predictability, or shared record
    neighborhoods among public observables;

causal proximity:
    directed access latency: how quickly one public record can influence
    or help recover another;

horizons:
    access boundaries where public center data remain available but
    private block data require delayed/global/nonlocal access;

geometry:
    the low-dimensional, stable, approximately metric structure inferred
    from these public-record and latency relations.
```

This differs from "geometry from entanglement" in emphasis.  Entanglement
may be part of the substrate, but geometry above the cut is reconstructed
from what observers can repeatedly access: redundant records,
distinguishability, latency, and recoverability.

Nearby literatures:

- decoherent histories / quasiclassical domains: classical spacetime
  histories after decoherence, usually with geometric variables already
  present;
- Quantum Darwinism: objective classical facts from redundant records;
- observer algebras in gravity: what a worldline/static-patch observer
  can access;
- quantum reference frames: localization and spacetime quantities
  relative to physical reference systems;
- entanglement/QEC geometry: geometry from entanglement or
  reconstructability, not specifically from public records above a cut.

Possible distinctive claim:

```text
effective geometry is the geometry of public centers, not of the full
private quantum state.
```

## 12. Ways this could fail against observation

Before developing the program, it should be checked against ordinary
spacetime phenomenology.  The following would be early failures or hard
constraints.

1. **Wrong dimensionality.**  Public-record relations must recover an
   effectively 3+1-dimensional macroscopic spacetime, with the observed
   large-scale dimension and local volume growth.  A generic record graph
   is high-dimensional, expander-like, or ultrametric; that would not
   resemble observed locality.

2. **No sharp causal structure.**  Access latency must produce a stable
   approximate light-cone structure.  If public records allow generic
   instantaneous long-range influence, or if the causal order is too
   observer-dependent at macroscopic scales, the result conflicts with
   relativistic causality.

3. **Lorentz invariance failure.**  A record-latency geometry could
   easily pick a preferred time slicing or environment frame.  Observed
   local physics strongly constrains preferred-frame effects, dispersion,
   and Lorentz-violating corrections.

4. **Equivalence-principle failure.**  Gravity couples universally.  If
   the public-record geometry depends strongly on the type of probe,
   internal composition, or information carrier, it would not reproduce
   the equivalence principle.

5. **Macroscopic objectivity without metric consistency.**  Quantum
   Darwinism can make many classical facts objective without making their
   relations metric.  The program fails if redundant records give
   objective objects but no consistent distances, durations, or inertial
   structure.

6. **Wrong gravitational dynamics.**  Even if access records yield a
   metric-like structure, they may not yield Einstein-like response,
   gravitational waves, lensing, perihelion precession, or the observed
   Newtonian limit.  Recovering public geometry is weaker than recovering
   gravitational dynamics.

7. **Failure of locality below the cut leaking above it.**  The private
   block algebra may be highly nonlocal.  That is acceptable only if the
   nonlocality remains hidden from low-complexity/public records.  If it
   leaks into ordinary observables, it would contradict local quantum
   field theory phenomenology.

8. **Thermodynamic arrow mismatch.**  Public records and redundancy are
   arrow-of-time dependent.  Geometry cannot depend pathologically on
   environmental record formation in a way that makes past spacetime
   unstable or observer-fragment dependent.

9. **Insufficient universality of records.**  Different observers must
   reconstruct compatible public geometry from overlapping records.  If
   access profiles produce many incompatible geometries with no stable
   intersubjective core, the program only gives perspectival records, not
   observed shared spacetime.

10. **Known horizon phenomenology.**  For black holes, the access
    geometry must still reproduce the coarse causal separation, Hawking
    thermality, no-hair behavior, scrambling/recovery constraints, and
    the observed semiclassical exterior.  An access-only model that gets
    Page/HP structure while losing semiclassical exterior locality is not
    enough.

Minimal survival criterion:

```text
public-record geometry must yield a stable, low-dimensional,
approximately Lorentzian, observer-compatible causal metric at
macroscopic scales, while hiding private-block nonlocality below the
operational cut.
```

This is a high bar.  The current constrained-access results support only
the public/private and horizon-access parts of the story.  They do not
yet recover dimensionality, Lorentz invariance, the equivalence
principle, or Einstein dynamics.

## 13. Current fork and next move

The exploration now has two tracks.

### Track A: algebraic access, near-term

Stabilize the finite-dimensional access theorem:

```text
A_code = direct sum_x B(H_x)

public center:
    Z(A_code) is redundantly distinguishable from small records;

private blocks:
    B(H_x) is decoupled from small records inside fixed x;

enlarged access:
    delayed/global algebra can recover the block information.
```

This track is already supported by the Darwinian/no-hair note.  It is
about public centers and private blocks, not yet about geometry.

Immediate checks:

1. verify the definitions against the stress-test examples;
2. decide whether the center-broadcast/block-private split follows
   naturally from monitored channels, or is merely an imposed condition;
3. keep the horizon specialization finite-resolution and quasi-static.

### Track B: geometry above the cut, exploratory

Ask whether the public-center records from Track A carry enough
structure to define an effective locality.

The first object should be an access relation, not a metric:

```text
R(i,j) = how strongly public record i predicts, redundantly overlaps
         with, or can influence/recover public record j.
```

Possible derived quantities:

```text
redundancy overlap:
    shared environmental fragments carrying both public labels;

mutual predictability:
    distinguishability or mutual information between public centers;

directed latency:
    minimum record/time depth before information at i affects or is
    recoverable from j;

access distance:
    a candidate distance extracted from redundancy loss or latency.
```

Only after this relation is defined should one ask whether it has
metric-like behavior, dimension, approximate light cones, or Lorentzian
structure.

### Guardrail

Do not assume geometry in order to recover it.  The input data should be
algebras, public records, fragments, distinguishability, recoverability,
and latency.  Any graph, metric, dimension, or causal cone should be a
derived summary of those access data.

The practical next step is therefore:

```text
define the minimal access-locality diagnostic on public centers,
then test it on simple systems before applying it to horizons.
```
