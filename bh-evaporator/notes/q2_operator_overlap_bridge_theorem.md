# Q2 Operator-Overlap Bridge Theorem

Date: 2026-07-05

Status: first theorem-class formulation.  This upgrades
`operator_overlap_latency_lemma.md` from an exact visible-algebra
obstruction to a usable record-channel certificate, but only for a
bounded-budget source-local class.  It is a necessary condition for
fast recovery, not a Hayden-Preskill sufficiency theorem.

## Result in One Line

For a source-local record channel built from bounded sequential
collisions, if every coupled source generator remains close to a
diary-blind algebra up to time `T`, then the emitted record channel up
to `T` is close in diamond norm to a diary-independent channel.
Therefore HP-style order-one recovery by time `T` requires order-one
integrated leakage into the coupled algebra, or else nonlocal/extra
access outside the record-channel class.

This is the algebraic version of a Lieb-Robinson arrival bound.

## Setup

Work in a code sector

```text
H_code = H_D tensor H_B,
```

with diary `D`, hidden sector `B`, and background state `tau_B`.  Let
`Q_D(X) = Tr_B[(I_D tensor tau_B) X]`.

Choose a diary-blind *-subalgebra `A_bl` of code-sector operators such
that every observable generated inside `A_bl` reduces to a scalar on
`D`:

```text
for X in A_bl,       Q_D(X) = c_X I_D.
```

The fixed-sector memory-burden application uses `A_bl` as the algebra
generated by the master mode plus diagonal burden tags; fixed-sector
memory ladder/coherence operators are outside it.

Let the record be produced by sequential bounded collisions with
record degrees of freedom `R_j`:

```text
V_j = exp[-i g_j H_j],
H_j = sum_mu X_{j mu} tensor Y_{j mu},
```

where `X_{j mu}` are Heisenberg-evolved source-side operators at the
emission time, `Y_{j mu}` act on the record degree(s), and
`||Y_{j mu}|| <= 1`.  Fresh ancillas are the cleanest target, but the
same perturbative bound applies to a persistent record mode if the
total interaction budget is bounded and the blind/reference evolution
is kept in the comparison channel.

For each collision define the generator's diary-visible defect

```text
eps_j = inf_{H_j^0 in A_bl tensor B(R_j)} || H_j - H_j^0 ||.
```

Let the total interaction budget be

```text
G_T = sum_{j <= T} |g_j| ||H_j||.
```

## Theorem: Integrated Blind-Algebra Bound

Let `N_T` be the emitted-record channel up to time `T`.  Let `N_T^0` be
the comparison channel obtained by replacing each `H_j` with a
minimizing blind generator `H_j^0`.  Then `N_T^0` is diary-independent,
and

```text
|| N_T - N_T^0 ||_diamond
  <= C exp(C G_T) sum_{j <= T} |g_j| eps_j.
```

Consequently there is a diary-independent channel `C_T` such that

```text
|| N_T - C_T ||_diamond
  <= C exp(C G_T) sum_{j <= T} |g_j| eps_j.
```

For bounded-budget channels (`G_T = O(1)`), order-one diary recovery by
time `T` requires

```text
sum_{j <= T} |g_j| eps_j = O(1),
```

unless the emission map is not source-local, the decoder has supplied
side information, or the comparison blind algebra was chosen too small.

## Proof Sketch

The blind comparison channel is diary-independent because its full
interaction algebra is generated inside `A_bl`, which is closed under
products and reduces to scalars on `D`.

For the perturbation bound, use the standard telescoping/Duhamel
estimate for products of unitaries:

```text
|| e^{-i g H} - e^{-i g H0} ||
  <= |g| ||H - H0|| exp(|g| (||H|| + ||H0||)).
```

Insert one collision replacement at a time and sum the errors.  Taking
the Stinespring dilation to the emitted record and tracing out the
unseen systems cannot increase diamond distance.  The final
diary-recovery obstruction then follows directly from the
visible-algebra lemma's data-processing step.

The constants are not the point; the invariant is the integrated
defect from the diary-blind algebra.

## Relation to the Old `G_D(t)` Notation

The older shorthand was

```text
G_D(t) = sup_{O in A_D, ||O||=1}
         || P_src[ U(t) O U(t)^dagger ] ||.
```

That is a useful routing diagnostic, but the theorem above is cleaner
if the computable profile is instead defined on the coupled generators:

```text
V_D(t_j) = eps_j / ||H_j||,

integrated visibility = sum_j |g_j| ||H_j|| V_D(t_j).
```

To replace `V_D` by the older `G_D`, one still needs a duality lemma
relating projection of diary operators into the source algebra to
distance of source generators from the diary-blind algebra.  In finite
dimension this may be true up to norm/convention constants for a fixed
Hilbert-Schmidt projection, but it is not automatic in operator norm.
This is an important calibration correction: the theorem should be
stated with `V_D` first, and `G_D` introduced only after the duality
choice is fixed.

## What This Decides

The Q2 bridge does not prove that large overlap gives HP recovery.  It
proves the converse obstruction:

```text
bounded-budget source-local records
+ small integrated diary-visible generator defect
    => no order-one diary recovery from the emitted record.
```

So fast recovery in the class must come from one of the named exits:

```text
1. actual routing/mixing into the coupled algebra;
2. nonlocal or constraint-dressed emission access;
3. supplied side information;
4. an order-one multi-time generated-algebra effect, which appears
   exactly as order-one integrated defect or failure of the bounded
   source-local class.
```

This is the bridge version of the access-cut result: public diagonal
tags may be visible, while fixed-sector diary coherences remain private
until the interaction algebra reaches them.

## Memory-Burden Application

In the strict prototype, for fixed-sector memory diaries:

```text
X_{j mu} in A_bl exactly,
eps_j = 0,
G_T arbitrary but finite.
```

Therefore the bound gives `N_T = N_T^0` on those coherences and the
record is exactly diary-independent.  The prototype does not need the
fresh-ancilla approximation; it sits at the zero-defect endpoint because
number conservation and the exchange graph forbid any memory ladder
operator from entering the visible algebra.

The black-hole mapping can still add rare memory-release channels
outside the strict algebra.  Those channels are not HP-fast in the
Dvali 2405.13117 branch and should be treated as a separate exit, not
as a failure of the strict obstruction.

## Drafting Consequence

For paper text, do not write "small single-time `G_D(t)` implies slow
recovery" without the bridge assumptions.  Write:

```text
small integrated distance of the source-local record generators from a
diary-blind algebra implies record-channel diary-independence;
therefore HP-fast recovery requires order-one integrated generator
access, nonlocal access, or supplied side information.
```

That phrasing survives the Lie-algebra-generation warning and keeps the
strict memory-burden countermodel in the exact-zero-defect class.
