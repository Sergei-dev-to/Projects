# Erosion Channel Review

## Purpose

Review the proposed erosion channel for the finite-gauge / residual-entropy
droplet, and check nearby literature.

The question:

```text
Can the evaporation step be made more than a bookkeeping isometry?
```

## What The Channel Must Do

For the `L x L` gauge droplet:

```text
dim H_L       = q^(L^2)
dim H_(L-1)   = q^((L-1)^2)
dim H_shell   = q^(2L - 1)
```

An erosion step must be an isometry:

```text
V_L : H_L -> H_(L-1) tensor H_hard(L) tensor H_soft(L).
```

It must satisfy:

```text
1. core shrinks from L to L - 1;
2. shell entropy q^(2L-1) leaves the core;
3. hard radiation carries energy epsilon_L ~ T_L ~ 1/L;
4. hard radiation alone is approximately thermal;
5. hard + soft exterior keeps the evolution unitary;
6. soft record is gauge/shell data, not arbitrary hidden qubits.
```

## Natural Factorization In The Counting Model

For the abelian `Z_q` gauge droplet, the physical Hilbert space can be
represented by independent plaquette flux variables after solving Gauss law.

For a square patch:

```text
H_L ~= tensor over L^2 plaquette-flux variables.
```

Then:

```text
H_L ~= H_(L-1) tensor H_shell(L)
```

where:

```text
dim H_shell(L) = q^(L^2 - (L-1)^2) = q^(2L - 1).
```

This is not an arbitrary tensor split of qubits. It comes from:

```text
Gauss-law solving / plaquette-flux coordinates.
```

Important caveat:

```text
Gauge-theory Hilbert spaces do not naively factorize under arbitrary spatial
cuts. Edge modes or extended Hilbert spaces are normally needed.
```

For our purpose, that is a feature:

```text
the emitted shell record should be understood as edge/flux data created by
moving the boundary.
```

## A Minimal Explicit Channel

Let:

```text
|a>_shell
```

be a basis of the shell flux Hilbert space.

Choose hard radiation energy bins:

```text
|h>_hard
```

with a thermal probability distribution:

```text
p_L(h) ~ g_h exp(-epsilon_h / T_L).
```

Define:

```text
V_L |i>_(L-1) |a>_shell
  = |i>_(L-1) tensor sum_h sqrt(p_L(h)) |h>_hard |a,h>_soft.
```

The soft states:

```text
|a,h>_soft
```

are mutually orthogonal.

This is an isometry because:

```text
<a,h|a',h'> = delta_aa' delta_hh',
sum_h p_L(h) = 1.
```

For any shell input state, tracing out the soft record gives:

```text
rho_hard = sum_h p_L(h) |h><h|.
```

So hard radiation is exactly thermal by construction, while the full hard+soft
output remains pure and preserves the shell information.

## Why This Is Useful

This channel cleanly realizes the desired hard/soft split:

```text
hard:
  carries energy and looks thermal;

soft:
  carries the shell flux information required by unitarity.
```

It is the finite-gauge-droplet analogue of:

```text
Hawking quanta + soft hair / edge memory.
```

## Why This Is Still Too Easy

The minimal channel is almost maximally protective of information.

It says:

```text
hard radiation is thermal because all information is routed to an orthogonal
soft record.
```

That is a useful baseline, but it risks becoming:

```text
thermal bath plus hidden archive.
```

To make the model interesting, later versions should impose at least one of:

```text
1. soft record is only the gauge edge/flux data allowed by boundary constraints;
2. soft record capacity is minimal, not arbitrarily enlarged;
3. hard and soft outputs are generated by local boundary moves;
4. soft records from different steps obey gauge matching constraints;
5. late hard radiation depends conditionally on earlier soft data;
6. early/late mutual information is computed, not assumed.
```

## Literature Support

### 1. Gauge edge modes and extended Hilbert spaces

Buividovich and Polikarpov argued that entanglement between gauge fields in
regions requires extending the physical Hilbert space. In that extended
description, a boundary flux Shannon entropy appears.

Donnelly decomposed lattice-gauge entanglement into:

```text
boundary representation / edge-state entropy;
non-Abelian representation-dimension term;
bulk nonlocal correlations.
```

This supports our interpretation:

```text
the shell record is not arbitrary;
it is boundary flux / edge-mode data created when the region boundary moves.
```

But these papers study spatial entanglement and factorization, not an
evaporating droplet channel.

### 2. Soft hair and hard/soft evaporation

Hotta, Nambu, and Yamaguchi explicitly model black-hole evaporation with:

```text
Hawking particle emission;
zero-energy soft-hair evaporation.
```

Their result is directly relevant to our split:

```text
hard radiation is not the whole information carrier;
soft degrees can be entangled with early/late radiation.
```

This is the closest black-hole-side precedent for our hard/soft channel.

But their model is a qubit black-hole model, not a non-gravitational
residual-entropy droplet.

### 3. Qubit transport models

Osuga and Page give an explicit unitary qubit-transport model transferring
black-hole information to Hawking radiation.

This supports:

```text
evaporation as a unitary map from shrinking core to growing radiation.
```

But it does not provide:

```text
area entropy from gauge constraints;
perimeter energy;
hard/soft shell flux records.
```

### 4. Random-unitary evaporation models

Piroli, Sunderhauf, and Qi study black-hole evaporation with random local
unitary circuits coupled to an environment. They find Page-like behavior and
information-retrieval times controlled by scrambling and coupling scales.

This supports using random/unitary channel baselines for information-flow
diagnostics.

But it does not give the thermodynamic core of our model.

## What Seems New In Our Combination

The individual ingredients are known:

```text
gauge edge modes;
unitary qubit transport;
random-unitary Page dynamics;
soft-hair information channels;
residual entropy in constrained systems.
```

The combination does not seem standard:

```text
finite residual-entropy gauge/ice droplet
with area entropy, perimeter energy, and a hard/soft shell erosion channel.
```

That is the potentially interesting result.

## Recommended Channel Hierarchy

### Level 0: Counting channel

Use the exact plaquette split:

```text
H_L = H_(L-1) tensor H_shell(L).
```

Move:

```text
H_shell(L) -> H_soft(L)
```

and attach a hard thermal energy bin.

This verifies bookkeeping.

### Level 1: Thermal hard channel

Use:

```text
V_L |a> = sum_h sqrt(p_L(h)) |h>_hard |a,h>_soft.
```

This gives hard thermality and exact unitarity.

This is the first real erosion channel, but still archive-like.

### Level 2: Minimal soft capacity

Require:

```text
dim H_soft(L) = dim H_shell(L),
```

or only a small overhead.

Then hard thermality cannot be produced by simply storing both `a` and `h`
orthogonally unless hard information is balanced by correlations.

This is more interesting.

### Level 3: Boundary-local gauge channel

Construct the channel from local edge moves:

```text
plaquette removal;
link/vertex update;
Gauss matching at the moving boundary;
emitted flux edge states.
```

This is the first version that could be called natural dynamics.

## Current Verdict

The erosion channel has strong literature support as a structure:

```text
gauge edge modes justify shell records;
unitary qubit transport justifies core-to-radiation isometries;
soft-hair models justify hard/soft radiation splits;
random-unitary models justify Page diagnostics.
```

But no source found gives our exact channel.

The honest status:

```text
The erosion channel is plausible and well-motivated, but still constructed.
```

The next useful calculation is:

```text
implement Level 1 and Level 2 channels and test hard-only thermality,
soft+hard purification, and early/late mutual information.
```
