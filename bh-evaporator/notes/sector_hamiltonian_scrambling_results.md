# Sector-Hamiltonian Scrambling Results

## Question

The energy-resolved sector Hamiltonian works if the remaining core is mixed
inside each sector after every emission step:

```text
p_n(a) -> P_n / dim H_n
```

This note checks whether that idealized rethermalization map can be replaced by
actual intra-sector Hamiltonian evolution.

## Script And Data

Script:

```text
sim/sector_hamiltonian_scrambling.py
```

Data:

```text
sim/data/sector_hamiltonian_scrambling_first.csv
sim/data/sector_hamiltonian_scrambling_two_seed.csv

```

## Construction

The core sector model is the successful energy-resolved one:

```text
H_core = direct sum_n H_n
dim H_n = 2^n
M_n = alpha sqrt(n)       black-hole-like case
M_n = alpha n             linear comparison case
E_{n,a} = M_n + epsilon_{n,a}
```

The sector density of states is exponential over a window of order `4 T_n`.

Emission is unchanged:

```text
Gamma_fi proportional to |<f,n-1|X_n|i,n>|^2 omega_fi^p
omega_fi = E_i^(n) - E_f^(n-1)
```

The mixing step is generated by an intra-sector Hamiltonian:

```text
U_n(tau) = exp(-i K_n tau)
p_n' = |U_n(tau)|^2 p_n
```

Three choices of `K_n` were tested:

```text
dense:
  GOE-like dense random symmetric Hamiltonian

expander:
  deterministic sparse expander-like adjacency Hamiltonian

sparse:
  sparse random symmetric graph Hamiltonian
```

This remains a secular population diagnostic. The Hamiltonian mixer supplies a
unistochastic population map in the energy basis.


Here `sectorTV` is the mean total-variation distance between the population in
each occupied sector and the uniform population in that sector. Smaller values
mean better intra-sector rethermalization.

The sparse random Hamiltonian at `tau = 4` also passes:

```text
case range over two seeds and two shrinkage maps:
  sqrt power = 1.087 to 1.107
  TV         = about 0.054 to 0.055
  sectorTV   = about 0.001 to 0.002
```

## Interpretation

This closes the main artificial step in the previous result.

The successful mechanism can now be stated as:

```text
energy-resolved sectors
+ intra-sector Hamiltonian scrambling
+ golden-rule shrinkage transitions
```

produce:

```text
local hard thermality,
shrinking core entropy,
accelerating power for M_n proportional to sqrt(n),
near-flat/decelerating power for M_n proportional to n.
```

This is a real improvement over the explicit rethermalization map. The model
replaces the primitive update:

```text
p_n(a) -> P_n / dim H_n
```

as a primitive update. A Hamiltonian mixer does the same job at the secular
population level.

## Remaining Caveat

The next limitation is the absence of a single autonomous Hamiltonian for core
plus radiation.

The present evolution alternates:

```text
1. intra-sector Hamiltonian mixing;
2. golden-rule emission channel.
```

This is the usual weak-emission/secular separation. The result now tells us the
natural autonomous target:

```text
H_total = H_core + K_scramble + H_rad + H_emission
```

where `K_scramble` must mix each remaining sector on a timescale shorter than
the evaporation timescale.

That target is more constrained than before. The autonomous Hamiltonian must
reproduce this effective sector-mixing plus emission-channel behavior.
