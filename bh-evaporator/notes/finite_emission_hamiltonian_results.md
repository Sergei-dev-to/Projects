# Finite Emission Hamiltonian Results

## Question

In the stitched evaporator, `U_emit` was still a designed emission block/channel.

The question here is:

```text
Can the golden-rule hard-bin distribution be implemented by an explicit finite
Hamiltonian interaction?
```

This targets both:

```text
F7:
  emission rates from matrix elements;

F15:
  a less black-box emission block inside the stitched cycle.
```

## Hamiltonian

Use one input state and several emitted-bin states:

```text
|in>, |h_1>, |h_2>, ..., |h_n>.
```

The emission Hamiltonian is:

```text
H_emit = sum_h g_h ( |h><in| + |in><h| ).
```

If:

```text
G^2 = sum_h g_h^2,
```

then starting from `|in>`:

```text
P_emit(t) = sin^2(G t),
P(h | emit) = g_h^2 / G^2.
```

So choose:

```text
g_h^2 / G^2 = p_h^golden.
```

The golden-rule target is:

```text
p_h ~ int_bin d omega omega^(d-1)
      exp[S(M - omega) - S(M)].
```

## Composition with Shrinkage Automaton

The same script checks that emitted finite energy labels can feed the reversible
shrinkage automaton.

Result:

```text
shrinkage injective after composition = True
```

So the composed update:

```text
Hamiltonian emission -> radiation bin -> accumulator/shrink automaton
```

remains compatible with reversible bookkeeping.

## Interpretation

This improves `U_emit`.

Before:

```text
the emitted-bin distribution was a channel with golden-rule weights.
```

Now:

```text
the emitted-bin distribution is generated by a finite Hamiltonian block whose
matrix elements encode the golden-rule weights.
```

This is closer to a standard weak-coupling/Fermi-golden-rule picture.

## Caveat

The couplings are still chosen to reproduce the golden-rule weights:

```text
g_h^2 proportional to p_h^golden.
```

So this does not derive the golden-rule distribution from a detailed bath
Hamiltonian. It embeds that distribution into an explicit finite Hamiltonian
interaction.

The next naturalness target would be:

```text
derive g_h^2 * bath_density_h from a finite bath spectrum and generic coupling.
```
