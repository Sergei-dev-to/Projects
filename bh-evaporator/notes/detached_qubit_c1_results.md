# Detached-Qubit C1 Results

## Purpose

This tests Option C1:

```text
deterministic boundary detachment
n-spin core -> (n-1)-spin core + one emitted radiation qubit
```

The question:

```text
Can a natural emitted-qubit radiation register give F8/F9 while retaining any
thermodynamic black-hole-like behavior?
```

## Implementation

```text
sim/detached_qubit_c1.py
```

```text
sim/data/detached_qubit_c1_summary.csv

sim/data/detached_qubit_c1_sqrt_seed2469.npz

```

Model:

```text
n = 10 -> 2
one boundary qubit detached per step
radiation qubit chain grows explicitly
local spin-chain Hamiltonian blocks
mass laws: sqrt and linear
```

Boundary detachment:

```text
|prefix>|b> -> |prefix>_core |b>_rad
```

The emitted qubits are explicit radiation time bins, so early/late radiation
subsystems are well-defined.

## Interpretation

C1 successfully gives the radiation architecture:

```text
explicit radiation qubit chain;
Page-like core/radiation Renyi-2 profile;
nonzero early/late radiation mutual information.
```

This is exactly why detached-qubit radiation is structurally better for F8/F9
than transition-record radiation.

But the information-side result is purely kinematic:

```text
S2(core) and I2(early:late) are identical for sqrt and linear mass laws.
```

The mass law affects only the energy bookkeeping:

```text
sqrt mass:
  emitted power increases because M_n - M_{n-1} increases as n shrinks.

linear mass:
  emitted power is approximately constant because M_n - M_{n-1} is constant.
```

So C1 does produce acceleration for the sqrt mass law, but not through a
matrix-element or W-profile mechanism. It is basically the analytic consequence
of the imposed mass schedule.

## Verdict

C1 is useful but insufficient.

It gives:

```text
F8: yes, Page-like radiation entropy in a clean emitted-qubit register.
F9: yes, early/late radiation structure in a clean emitted-qubit register.
```

But it weakens:

```text
F6/F7/F11: acceleration is not dynamically generated by an emission channel.
```

The result is too close to standard kinematic qubit-transport/Page models
unless we add an energy-selective or rate-selective evaporation mechanism.

## Next Step

Move to C2:

```text
energy-filtered detached-qubit emission.
```

The goal is to keep:

```text
explicit emitted radiation qubits
```

while restoring:

```text
matrix-element-derived / W-profile thermodynamic dynamics.
```

Minimum C2 requirement:

```text
1. no deterministic one-qubit-per-step schedule;
2. emission probability depends on energy-lowering overlap;
3. sqrt mass accelerates more robustly than linear;
4. radiation remains a small emitted-qubit/time-bin register;
5. Page/early-late diagnostics remain computable.
```
