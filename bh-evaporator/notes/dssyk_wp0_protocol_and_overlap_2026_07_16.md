# DSSYK WP0: Primary-Source Overlap and Protocol Specification

Date: 2026-07-16

Status: **completed with a conditional protocol gate**. The bounded literature
pass did not find a DSSYK diary-record, process-distance, or recovery
calculation. The doubled equal-energy kinematics, shell code, time convention,
and a minimal detector channel are fixed below. However, the gauge-invariant
algebra currently derived in the literature is not by itself a restricted
observer protocol: it contains all bounded system operators. A claim of
constraint-induced access therefore requires an additional, independently
specified implementation or complexity budget before WP2.

This note is the WP0 deliverable for
`observer_relative_temporal_access_successor_proposal_2026_07_16.md`.

## 2. Attribution and exact kinematics

### 2.1 The doubled equal-energy construction

Narovlansky and Verlinde are the primary source for the specific doubled
equal-energy model. In sections 2.1--2.3 of
[arXiv:2310.16994](https://arxiv.org/abs/2310.16994), they impose

```text
(H_L-H_R)|phys> = 0,                                    (2.1)
```

take identical disorder so that each right eigenstate is paired with a unique
left eigenstate,

```text
|E_i>_phys = |E_i>_L |E_i>_R,                           (2.2)
H_phys = (H_L+H_R)/2,                                   (2.3)
```

and explicitly state that the doubled physical spectral density equals the
single-SYK spectral density. The physical time is generated by `H_phys`.
Physical operators commute with `H_L-H_R`; their concrete scaling-operator
family is produced by group averaging a left-right product over the relative
time flow.

Consequently,

```text
rho_phys(E) = rho_DSSYK(E), not rho_DSSYK(E)^2.          (2.4)
```

This statement is sector-wise. At finite `N`, first fix the common fermion
parity and any antiunitary-symmetry sector so that the spectrum is
nondegenerate. If an energy has multiplicity `g_E>1`, the full kernel of
`H_L-H_R` has multiplicity `g_E^2`; the one-copy map then describes a declared
diagonal paired subspace unless an additional pairing or gauge fixing is
specified.

### 2.2 What belongs to the Rahman--Susskind line

Rahman and Susskind independently developed the DSSYK-at-infinite-temperature
de Sitter proposal and its separation-of-scales interpretation. Their
[comments on Narovlansky--Verlinde](https://arxiv.org/abs/2312.04097) describe
the NV paper as a different version of the conjecture, criticize two scale
identifications, and expressly do not analyze NV's dressed-correlator
construction. Their later temperature and chord papers continue that
interpretive program.

They are therefore proper anchors for the broader DSSYK/de Sitter motivation
and for a competing scale dictionary, but not co-primary sources for the
doubled equal-energy construction. The attribution rule is:

```text
doubled equal-energy model: Narovlansky--Verlinde;
independent DSSYK/dS and separation-of-scales line: Rahman--Susskind. (2.5)
```

### 2.3 Relational reconstruction

Aguilar-Gutierrez
[arXiv:2506.21447](https://arxiv.org/abs/2506.21447) recovers the doubled
system as a symmetry sector of chord space, imposes relative-time
translations, and derives conditioned relational operators. Two statements
are load-bearing for this program:

1. after the constraint, the system is isomorphic to one DSSYK without matter,
   although it is probed by a paired observer;
2. the chord-space kinematical gauge-invariant algebra is generated using
   `A in B(H_0^S)` and is Type `I_infinity`; at finite microscopic dimension
   the corresponding full matrix algebra is Type `I_n`.

Thus the relational construction supplies a clock and a gauge-invariant
dressing map, but it does not select a small operational algebra. If every
bounded `A` is allowed, the isometric one-copy equivalence is exact.

## 4. Finite-shell diary definition

Work per finite-`N` disorder realization `omega`, with identical left and
right couplings. Let `E_*` be the target energy. The primary finite-size shell
is a fixed-rank microcanonical shell containing the `2m` eigenvalues nearest
`E_*`:

```text
I_omega(E_*,m) = {E_1,...,E_(2m)},                       (4.1)
P_omega = sum_(a=1)^(2m) |E_a,E_a><E_a,E_a|.            (4.2)
```

The induced width `Delta E_omega=max I-min I` is reported for every
realization. Accept a realization only when

```text
mean level spacing << Delta E_omega
and
Delta E_omega << the spectral-envelope variation scale. (4.3)
```

Fixed rank, rather than a fixed numerical width, keeps the code dimension and
twirl identical across finite realizations. A later scaling analysis must
show that (4.3) has a common window; WP0 does not assume it.

The first diary is classical and binary. Order the levels by energy and set

```text
|d_0>_omega = (1/sqrt(2m)) sum_a |E_a,E_a>,             (4.4)
|d_1>_omega = (1/sqrt(2m)) sum_a (-1)^a |E_a,E_a>.      (4.5)
```

These states are orthogonal and have exactly the same fine-grained energy
probabilities. Their distinction is a phase pattern, not an energy header.
The encoder is fixed by energy rank before any detector outcome is generated,
so the label survives as a well-defined per-realization object. This does not
yet define a protected quantum code; claims of quantum payload recovery are
not allowed at this stage.

## 5. Minimal NV detector channel

Choose one scaling dimension `Delta` before inspecting diary outcomes. Let
`O_Delta^phys(tau)` be the NV group-averaged, constraint-preserving operator.
On the shell define the bounded Hermitian detector observable

```text
B_(Delta,omega)
  = P_omega [O_Delta^phys(0)+O_Delta^phys(0)^dagger] P_omega / 2,
A_(Delta,omega) = B_(Delta,omega)/||B_(Delta,omega)||,    (5.1)
```

discarding a realization only if the denominator vanishes. Its native-time
translate is

```text
A_(Delta,omega)(tau)
  = exp(i H_phys tau) A_(Delta,omega) exp(-i H_phys tau). (5.2)
```

For pre-registered times `tau_j` and couplings `g_j`, initialize a fresh qubit
record `R_j` in `|+>`, apply

```text
U_j = exp[-i g_j A_(Delta,omega)(tau_j) tensor Z_(R_j)/2], (5.3)
```

retain all earlier records, and trace the final DSSYK system. This defines

```text
N_K^(Delta,omega): b in {0,1} -> rho_(R_1...R_K|b).      (5.4)
```

The full record state is retained, so no measurement basis is optimized after
seeing the result. There is no added Page--Wootters clock: `tau` is the native
physical/relational time, and the record qubits are detector memory only.

The protocol restriction in (5.1)--(5.3) is motivated by NV's explicit simple
scaling-operator detector. It is not a consequence of the full relational
algebra in Aguilar-Gutierrez.

## 6. Disorder rule

The primary result is per realization:

```text
delta_K(omega)
  = (1/2)||N_K^(omega)(0)-N_K^(omega)(1)||_1.            (6.1)
```

Report the sample mean, variance, shell width, and rejection rate. Do not
average the channel before inserting the rank-defined phase code. The
existing `self_averaging_variance.md` result controls a Renyi-purity statistic
under stronger ETH moment assumptions; it does not establish concentration
of (6.1).
