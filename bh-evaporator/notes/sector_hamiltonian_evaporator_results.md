# Sector-Hamiltonian Evaporator Results

## Question

Can the area-register model be written as an explicit sector Hamiltonian whose
evaporation rates are generated by matrix elements?

## Construction

Script:

```text
sim/sector_hamiltonian_evaporator.py
```

Data:

```text
sim/data/sector_hamiltonian_evaporator_summary.csv
sim/data/sector_hamiltonian_evaporator_timeseries.csv
sim/data/sector_hamiltonian_evaporator_best.npz
```

The model uses sector Hilbert spaces:

```text
H_core = direct sum_n H_n
dim H_n = q^n
S_micro(n) = n log q
```

with two mass laws:

```text
black-hole-like case:
  M_n = alpha sqrt(n)

linear control:
  M_n = alpha n
```

Each sector has a Hamiltonian block:

```text
H_n = M_n I + delta H_n
```

where `delta H_n` is a small random symmetric perturbation. Shrinkage is
generated by maps:

```text
X_n : H_n -> H_{n-1}
```

Two choices were tested:

```text
local:
  remove/project one qudit

scrambled:
  orthogonally rotate the same removal map on domain and codomain
```

For each energy eigenstate transition:

```text
|i,n> -> |f,n-1>
```

the emitted energy and rate are:

```text
omega_fi = E_i^(n) - E_f^(n-1)

Gamma_fi proportional to
  |<f,n-1| X_n |i,n>|^2 omega_fi^p
```

subject to the chosen emission passband.

The time evolution in this diagnostic is secular/rate-level:

```text
p_{n-1,f}(t+1) receives Gamma_fi p_{n,i}(t)
p_{n,i}(t+1) loses sum_f Gamma_fi p_{n,i}(t)
```

This is a Hamiltonian-derived Markov/secular evaporator. A full state-vector
version remains a separate upgrade.

## Diagnostics

The script computes:

```text
energy(t)
area-sector expectation n(t)
dimension entropy S_micro(t)
second Renyi entropy of the remaining core distribution
jump probability
emitted power
conditional emitted energy
outgoing weighted phase space W = sum_f Gamma_fi omega_fi
hard-spectrum distance from a thermal x = beta omega distribution
```

The thermal spectrum comparison uses bins in:

```text
x = beta_n omega
```

and compares the generated number distribution to:

```text
P(x) proportional to x^p exp(-x)
```

where `p` is the bath/ohmic power used in the rate.

## Result

Default parameters:

```text
n = 4,...,10
q = 2
alpha = 8
bandwidth = 0.25
pmax = 0.08
steps = 80
sqrt mass passband max gap = 4
linear mass passband max gap = 12
seeds = 2468, 2469
```

Summary:

```text
case                         power    jump     omega    W        TV
local sqrt seed=2468          1.125   1.044   1.077   1.125   0.777
local linear seed=2468        0.906   0.907   0.999   0.906   0.826
scrambled sqrt seed=2468      1.125   1.045   1.077   1.125   0.777
scrambled linear seed=2468    0.906   0.907   0.999   0.906   0.826
local sqrt seed=2469          1.123   1.045   1.075   1.123   0.774
local linear seed=2469        0.906   0.907   0.999   0.906   0.826
scrambled sqrt seed=2469      1.123   1.045   1.075   1.123   0.775
scrambled linear seed=2469    0.906   0.907   0.999   0.906   0.826
```

Columns:

```text
power = mid/early emitted power
jump  = mid/early jump probability
omega = mid/early conditional emitted energy
W     = mid/early outgoing weighted phase space
TV    = mean total-variation distance from the thermal x-spectrum
```

For the square-root mass law, emitted power accelerates. Both the jump
probability and the conditional emitted energy contribute. For the linear mass
law, emitted power decelerates, and the conditional emitted energy is nearly
constant.

The local and scrambled removal maps give almost the same numbers. In this
sector-Hamiltonian diagnostic, the mass/entropy sector structure dominates the
result.

## What This Fixes

This addresses the strongest schedule objection for the acceleration result.

The evaporation rate is now generated from:

```text
sector Hamiltonian eigenvalues,
shrinkage-operator matrix elements,
emitted-energy weights,
state populations.
```

The square-root mass law accelerates while the linear control decelerates.
That means the acceleration is tied to the black-hole-like mass/entropy
relation and the resulting weighted outgoing channels.

The outgoing weighted phase-space diagnostic remains exact at this level:

```text
P(t) = <W>_t
W_i = sum_f Gamma_fi omega_fi
```

and the observed acceleration tracks the growth of `<W>_t`.

## Remaining Gap

The hard spectrum is still weak.

The total-variation distance from a thermal distribution in `beta omega` is
large:

```text
TV about 0.77 for the square-root mass law
TV about 0.83 for the linear control
```

So this sector Hamiltonian produces the right qualitative rate behavior, but
its emitted-energy distribution is too narrow/coarse to count as a generated
Hawking spectrum.

This is the main remaining technical gap for this branch.

## Current Reading

The sector-Hamiltonian result is worth keeping.

It gives a cleaner statement than the older repeated-cycle model:

```text
An entropy-correct finite area register with M_n proportional to sqrt(n)
generates accelerating evaporation from golden-rule sector transitions, while
the corresponding linear mass law decelerates.
```

The next improvement should target the spectrum. The
natural next construction is to keep the sector Hamiltonian and replace the
single coarse shrinkage transition with a hard-mode/bath channel that allows
many small emitted energies inside one area-sector step or between nearby
subsectors.
