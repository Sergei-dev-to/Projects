# Reviewer-Acceptable Model Desiderata

## Goal

Describe the model properties needed for a non-gravitational quantum evaporator
that would be hard to dismiss as bookkeeping.

The target is:

```text
one autonomous quantum system;
ordinary non-gravitational degrees of freedom;
black-hole-like evaporation phenomenology measured from the dynamics.
```

## Core Requirements

### 1. One autonomous Hamiltonian

The model should have a single time-independent Hamiltonian on a fixed Hilbert
space:

```text
|psi(t)> = exp(-i H_total t) |psi(0)>.
```

Avoid:

```text
external update schedules;
threshold rules;
changing Hilbert spaces;
externally declared emission events.
```

### 2. Non-gravitational microscopic variables

The microscopic variables should be ordinary quantum degrees of freedom:

```text
spins;
bosons;
matrices;
rotors;
oscillators;
graph or connector modes.
```

The model should not use horizon geometry, Einstein equations, or an imposed
gravitational background.

### 3. Emergent core/radiation split

The core/radiation split should be identified from the state or configuration,
not declared only as a bookkeeping label.

Acceptable examples:

```text
bound clump versus separated constituents;
active connected component versus detached modes;
localized aggregate versus outgoing waveguide occupation;
matrix eigenvalue clump versus escaped eigenvalue.
```

The split may be approximate, but the diagnostic must be explicit.

### 4. Natural shrinking active state count

The active core state count should decrease because the system evolves into a
smaller active object plus radiation.

Acceptable mechanisms:

```text
one constituent separates from a clump;
one active component loses incident connector modes;
one many-body aggregate loses particles;
one matrix eigenvalue escapes and its off-diagonal modes decouple.
```

Weak mechanisms:

```text
manual B_n -> B_{n-1} maps;
external area-register updates;
qubit deletion by rule.
```

### 5. Area-like entropy from model structure

The active core entropy should scale approximately as

```text
S_core ~ M^2
```

because of the model architecture, not because sector dimensions were assigned
to match the black-hole law.

Reviewer-friendly mechanisms:

```text
pairwise/off-diagonal modes among N active constituents;
matrix degrees of freedom inside an N-clump;
relational connector modes on an active graph.
```

Numerical evidence can be approximate, but the entropy count must be measured
or derived from the model degrees of freedom.

### 6. Mass or energy measured from H_total

The analogue of mass should be a measured core energy or a conserved charge
whose core/radiation split is defined.

Avoid treating mass as a label unless the label is directly tied to an
observable.

### 7. Negative heat capacity measured microcanonically

The model should show that the remaining active core heats as it loses energy:

```text
dT_core / dE_core < 0.
```

Acceptable diagnostics:

```text
microcanonical caloric curve;
DOS-derived beta(E);
post-emission clump heating;
kinetic or internal temperature proxy for the remaining core.
```

### 8. Emission generated by matrix elements

Radiation should be produced by the Hamiltonian coupling the core to outgoing
states.

Emission rates should come from:

```text
transition matrix elements;
density of final states;
radiation phase space.
```

Avoid assigning Hawking probabilities directly.

### 9. Hard radiation spectrum measured as flux

The emitted spectrum should be measured as asymptotic occupation or
time-integrated outgoing flux.

The natural comparison target is:

```text
rho_rad(omega) exp[S_core(E - omega) - S_core(E)]
```

with radiation phase-space factors included.

Final finite-chain occupation alone is not enough, because it can be distorted
by propagation and return.

### 10. Accelerating evaporation measured

The model should show emitted power increasing as the core shrinks:

```text
P(t) increases as M_core decreases.
```

The strongest target is an approximate Schwarzschild-like window:

```text
P ~ M^-2.
```

### 11. Scrambling or internal mixing

The active core should mix information on a timescale shorter than or comparable
to the evaporation timescale.

Useful diagnostics:

```text
operator spreading / OTOC;
entanglement growth;
spectral statistics;
ETH-like reduced observables;
comparison with no-scrambling or integrable controls.
```

### 12. Unitary information flow

The global evolution should remain pure/unitary.

The information diagnostics should be measured:

```text
core-radiation entanglement;
radiation entropy versus time;
early/late radiation mutual information;
hard/soft radiation correlations when a soft sector exists.
```

Page-like behavior alone is not enough; it must coexist with the thermodynamic
and emission diagnostics above.

### 13. Robustness controls

The model should be tested against:

```text
several initial-state classes;
several seeds or parameter choices;
controls that reduce or remove scrambling;
controls that suppress escape/emission;
controls that change radiation phase space;
controls that break or weaken pairwise/area-like entropy.
```

### 14. Finite-size honesty

Small models are acceptable only if the finite-size limitations are explicit.

The work should identify:

```text
which effects are already robust;
which effects improve with size;
which effects may be finite-size artifacts;
which diagnostics remain out of reach.
```

## Summary Standard

The strongest acceptable presentation would be:

```text
Here is H_total.
Here is the fixed Hilbert space.
Here is the initial state class.
Here is how core and radiation are identified from the state.
Here are measured S(E), T(E), emitted spectrum, power, and radiation entropy.
Here are controls showing which mechanisms are responsible.
```

Meeting this standard would not prove a model of real black holes. It would
show that the evaporation package is generated by an ordinary autonomous
quantum system rather than by an explicit evaporation schedule.
