# Quantum/Gravity Demarcation Ledger

## Purpose

This note is the steering document for the demarcation program.

The goal is to locate sharp boundaries between:

```text
ordinary quantum mechanics;
engineered or supplied quantum structure;
gravitational/holographic structure.
```

The working thesis is:

```text
Factorized quantum mechanics can reproduce the exterior information-processing
package once a small set of structures is supplied. Gravity is where those
structures become natural and mutually tied together.
```

The point is to identify exactly where gravity enters.

Use two categories:

```text
Crossable seams:
  gravity supplies an input, and ordinary QI/stat mech consumes it.
  State count, softness, emission access, and channel-genericity mostly have
  this character.

Structural seams:
  gravity changes the algebraic question, especially the definition and
  redundancy of subsystems. Constraint/dressing and geometric completion have
  this character.
```

## Search Protocol

Every future literature search or model attempt should specify which boundary
row it targets.

Use this checklist:

```text
1. Which row is being tested?
2. Is the relevant feature generic in ordinary local quantum mechanics?
3. If not, is it supplied by an engineered model family?
4. If supplied, is the supply rule natural or imposed?
5. Does a known gravitational/holographic construction make it natural?
6. Does the feature also require radiation/export access?
```

This prevents two recurring mistakes:

```text
calling standard quantum-information behavior gravitational;
calling a supplied Hamiltonian input a derived microscopic origin.
```
