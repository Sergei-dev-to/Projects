# Access Geometry and Export

Date: 2026-06-18

Role: result stack / conceptual bridge

Status: current synthesis note

## Core Claim

Private recovery has two bottlenecks. In staged source-local models this
gives the recovery-window estimate

```text
t_rec <= t_access + t_export
```

with a matching lower bound from `t_access` before the light cone reaches
the access channel. Constants, logarithmic error budgets, overlap between
the stages, and model-dependent mixing overheads are charged to the two
terms.

The first bottleneck is geometric or algebraic:

```text
t_access:
    time/resources needed for private information to enter the allowed
    access algebra or export-active block
```

The second bottleneck is information-theoretic:

```text
t_export:
    time/resources needed for the allowed records to decouple the diary
    reference from the remaining private source
```

The latency theorem controls the first from below in source-local
finite-velocity models. Decoupling/recovery controls the second.

This is the current technical spine of the constrained-access program:
separate the access obstruction from the export/recovery condition.

The additive form is a sequential upper bound. In chaotic dynamics,
access, scrambling, and export may overlap; then the actual recovery
time can be closer to

```text
max(t_access, t_export)
```

than to their sum. The robust statement is the window:

```text
t_access <= t_rec <= t_access + t_export
```

in staged source-local models, with the upper end improved whenever the
stages overlap.

## The General Schema

Start with:

```text
source system S
public/access record channel R
private diary D entangled with reference R_D
allowed side information E independent of D at deposit time
remaining source C
```

The diary is recoverable from records when there is a decoder

```text
R E -> D_hat
```

with high entanglement fidelity.

The obstruction:

```text
if the diary-to-record channel N_t is close to a constant channel,
then no decoder on the records can recover D.
```

For source-local finite-velocity access:

```text
||N_t - C_t||_diamond <= epsilon_LR(t)
```

before the diary reaches the access region.

The recovery condition:

```text
||rho_{R_D C} - rho_{R_D} tensor rho_C||_1 <= epsilon
```

Then information-disturbance / decoupling gives a recovery map from
records plus admissible side information.

The capacity floor:

```text
log d_R >= k - O(error terms)
```

for a k-qubit diary. Equivalently, if the record channel emits at most
`c_R` qubits per step,

```text
t_export >= (k - O(error terms)) / c_R.
```

This is the export-side lower bound paired with the access lower bound:
fast access geometry cannot make a diary-sized quantum message emerge
through a sub-diary-sized coherent record.

So the recovery problem factors into:

```text
access:
    get D into the algebra/channel that can emit records

export:
    make the emitted records reconstructive by decoupling R_D from C
```

In dressed or nonlocal-access cases, `t_access` is not necessarily a
time along a graph. It is the cost, or absence of cost, of having the
private algebra included in the allowed access algebra.

## Case Map

### 1. Ordinary Local Reservoir

For a `d`-dimensional local reservoir of entropy/size `S`:

```text
t_access ~ diameter ~ S^{1/d}
```

for worst-case deposits.

Even if export is efficient once the diary reaches the access region,
location-uniform recovery is power-law delayed, provided the allowed
records are generated by source-local finite-velocity access and the
side information does not already contain the diary:

```text
t_rec >= Omega(S^{1/d})
```

This is the slow routed branch.

### 2. Directed Local Channel

A conveyor or drift-scrambler has:

```text
t_access = L/v
```

and can have exact or HP-style export after arrival.

This shows that the source-local latency lower bound can be tight:

```text
t_rec = routing time + export budget.
```

It is engineered, but it proves the positive local branch is nonempty.

### 3. Log-Diameter Expander

For a bounded-degree expander with access radius:

```text
R_X(S) = O(log S),
```

the same theorem gives:

```text
t_access = O(log S)
```

if the dynamics collects the diary into an export-active block on that
timescale.

With a decoupling-capable export window:

```text
t_rec = O(log S + k + log(1/epsilon) + log(1/delta)).
```

This realizes the fast-routing branch conditionally. The expander does
not remove locality; it changes the access geometry.

### 4. Dressed Or Nonlocal Access

If recovery survives while source-local routing is frozen, then the
allowed access algebra is not generated by source-local emission in the
chosen factorization.

Then:

```text
t_access
```

is not a graph-routing time in the naive source variables. Relative to
the chosen factorization, the private information is reconstructible
through a dressed or nonlocal access algebra.

This is the branch relevant to Gauss-law dressing, holography of
information, and boundary reconstruction. It is a classifier once the
factorization and access algebra are fixed.

### 5. Measurement / Quantum-Classical Cut

The public side of measurement is different:

```text
public data:
    redundantly copied center / pointer sector
```

Publicization can be fast:

```text
t_public small.
```

The private side asks a different question:

```text
what does it take to recover phase/coherence/private block information?
```

In this language, quantum-to-classical emergence may exhibit a scale
separation:

```text
t_public << t_private_recovery.
```

The technical question is whether `t_private_recovery` is controlled by
the same two bottlenecks:

```text
access to the private complement
export/reversal of private coherence into allowed records
```

This is the bridge to the Heisenberg-cut direction. It is not yet a
claim that horizons and measurements are the same structure.

## What This Adds

The earlier classification said:

```text
fast private recovery requires fast routing/scrambling or nonlocal/dressed access.
```

The current synthesis refines that into:

```text
fast private recovery requires fast access geometry
and coherent export.
```

More precisely, it requires fast access in the chosen factorization, or
an allowed algebra for which the private information is already dressed
into the access channel, together with coherent export/recovery from the
records actually collected.

The two conditions are independent.

Fast access without export gives visibility without recovery:

```text
OTOCs can be large while R_D remains correlated with C.
```

Export without fast access gives ordinary routed recovery:

```text
records recover the diary only after the diary reaches the channel.
```

Dressed/nonlocal access changes the meaning of `access`:

```text
the allowed algebra already reaches behind the naive cut.
```

## Validity Boundaries

The synthesis should be read as a theorem schema, not as a universal
identity.

```text
source-local finite-velocity models:
    t_access is bounded below by graph/light-cone routing

staged export models:
    t_export is controlled by decoupling/recovery

dressed/nonlocal models:
    t_access is algebraic, not necessarily temporal

measurement-cut models:
    the public/private scale separation is a target, not yet a theorem
```

The most important warning is:

```text
visibility is not recovery.
```

Large commutators, OTOCs, or boundary sensitivity can show that the
diary has become visible to an access channel. They do not by themselves
show that the emitted records decouple the diary reference from the
remaining source.

### Target B: Expander Fast Routing

Concrete module:

```text
level2_expander_mixer_theorem.md
```

Prove in a theorem-backed expander model:

```text
t_rec = O(log S + export budget)
```

Current status:

```text
conditional theorem module exists
theorem-backed mixer route is available
moment-gap export criterion is now in main.tex
deterministic expander Hamiltonian export is reduced to proving the
second-moment/export gap
```

This is the load-bearing existence target. The random/design-mixer
version is closer to a theorem than the deterministic Hamiltonian
version: choose an explicit mixer with a known design or decoupling
bound on a logarithmic-diameter sparse graph, then compose:

```text
expander access radius:
    O(log S)

theorem-backed mixer:
    scrambling/export bound from the chosen construction

decoupling:
    HP recovery budget
```

The non-tautological ingredient is the access geometry. The random/design
mixer supplies a controlled export theorem; the expander supplies the
reason location-uniform access can be logarithmic rather than
power-law. A fixed deterministic expander Hamiltonian would be the
physical strengthening, not the first existence proof.

With Brown-Fawzi-style random-circuit decoupling, the export term is
polylogarithmic in the active block size. With an ideal TPE/design
primitive, the export term is whatever implementation depth that
primitive carries. The theorem should state this dependence explicitly.
The export capacity bound gives the matching floor in the diary size:
even with logarithmic access, a record channel of bandwidth `c_R` must
spend at least order `k/c_R` steps exporting a k-qubit diary.

The deterministic bridge is now:

```text
second-moment channel M_2 of the expander dynamics
contracts in the small-subsystem decoupling norm for the diary/record
partition
=> export condition
=> recovery.
```

So the hard target is no longer "show scrambling" in general. It is:

```text
prove gamma_2 >= 1/polylog(S)
```

for the relevant second-moment/export gap with prefactor controlled by
the diary and record budget, or find an expander dynamics whose operator
growth is fast while this export gap fails. A global-design route is too
strong for the latency target because its initial deviation can scale
with the full source size.

## Consequences For The Program

The broad goal is no longer just:

```text
horizon as constrained access.
```

The sharper program is:

```text
constrained access creates a public/private split;
private recovery is governed by access geometry plus export;
horizon-like systems are those where the private recovery bottleneck is
logarithmic or dressed rather than ordinary local power-law.
```

This still does not derive gravity or geometry. It gives a quantitative
test for when an access interface behaves horizon-like:

```text
public data are easy;
private data require either log-depth access geometry, coherent export,
or dressed/nonlocal reconstruction.
```

The same language may apply to measurement cuts, but only if it produces
a new quantitative public/private recovery separation.
