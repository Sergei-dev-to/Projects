# Firm road after the G branch

Date: 2026-06-14

Status: consolidation note.  Purpose is to record what survived from the
speculative branch about quantum/classical cut sharpness, geometry, and
Newton's constant, and to refocus on the firm constrained-access result.

## What is firm

The current strongest result is the access-latency mechanism
classification:

```text
finite LR velocity + source-local emission
=> no location-uniform fast recovery of arbitrary private deposits.
```

Equivalently:

```text
location-uniform fast private recovery
=> fast internal routing/scrambling
   OR nonlocal/dressed access.
```

This is an information-theoretic obstruction.  Before the routing time,
the reduced emitted record channel is close to constant on the diary, so
no measurement or decoder on the record recovers the private information.

This result supports the horizon-as-access-interface picture:

```text
public center:
    no-hair / thermodynamic / pointer data can be redundantly classical;

private blocks:
    microstate or diary data remain absent from small/passive records;

fast recovery:
    requires scrambling/routing or dressed/nonlocal access.
```

## What the cut-sharpness branch added

The quantum/classical cut can be assigned a useful access diagnostic:

```text
S_cut = xi/gamma
```

where

```text
xi:
    one-record Chernoff/Fisher rate for public-center distinguishability;

gamma:
    one-record leakage rate for private/block information.
```

For the minimal binary record model,

```text
S_cut ~= (public record strength / private leakage)^2.
```

This explains why the quantum/classical cut can be extremely sharp in
ordinary measurement: public pointer data may leak rapidly while
incompatible phase/private data leak only through tiny imperfections or
global correlations.

This is useful as a diagnostic of classical emergence.  It is not by
itself a route to gravity.

## What is parked

The attempt to get Newton's constant from cut sharpness should be parked.

Reason:

```text
xi/gamma:
    dimensionless access sharpness;

G:
    dimensional response coefficient.
```

To get a `G`-like number one needs additional geometric/thermodynamic
structure:

```text
area density of public/access degrees,
entropy capacity per area,
constraint dynamics,
universal coupling,
response law relating public geometry to energy.
```

That returns to Jacobson, holography, induced gravity, entanglement
equilibrium, or related response-law programs.  The constrained-access
work can interact with those ideas, but cut sharpness alone cannot
derive `G`.

The reasonable parked statement is:

```text
constrained access may quantify when variables become classical/public;
gravity would require an additional public constraint/response layer.
```

## Current destination

Do not make the immediate goal "derive geometry" or "derive G."

The near-term destination is:

```text
horizons as constrained-access quantum/classical interfaces.
```

The theorem shape:

```text
redundant records select a public classical center;
small/passive records are private for noncommuting blocks;
fast recovery of private blocks requires scrambling/routing or
nonlocal/dressed access.
```

This is broad enough to connect measurement, Quantum Darwinism,
black-hole information, and dressed gravitational access, but narrow
enough to be theorem-driven.

## Next result-facing steps

1. **Stress-test the access-latency classification.**

   Apply the two-branch mechanism map to:

   ```text
   ordinary local reservoir;
   fast scrambler / stretched horizon / HP;
   holography of information / Gauss-law dressing;
   AdS boundary reconstruction;
   Rindler;
   BTZ.
   ```

   The classification is valuable only if it sorts these cases without
   special pleading.

2. **Choose quantitative public-center stability.**

   The qualitative public-center statement is imported from
   no-broadcasting, Quantum Darwinism, and SBS.  The public side now
   needs a quantitative approximate version:

   ```text
   many redundant stable records
   => approximately commuting public algebra
   => effective center/block decomposition.
   ```

   The task is to choose the objectivity criterion and the stability
   constants, not to claim the qualitative result as new.

3. **State the horizon-interface theorem.**

   Combine:

   ```text
   public center stability;
   private-block decoupling;
   access-latency classification;
   Page/HP or dressed recovery.
   ```

   This is the point where the program becomes more than a collection of
   diagnostics.

4. **Keep cut sharpness as a diagnostic.**

   Use `S_cut=xi/gamma` for examples and intuition, especially ordinary
   measurement versus horizon channels, but do not ask it to produce
   metric dynamics.
