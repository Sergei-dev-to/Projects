# Program Status After Recalibration

Date: 2026-06-18

Role: result stack / program compass

Status: current

## Current Center

The program began from black-hole evaporation and the operational
horizon. Its rigorous center is now broader:

```text
constrained access -> public / de-protected / protected / recoverable
information sectors
```

The central distinction is:

```text
publicization != de-protection != coherent export
```

This distinction is the part of the program that currently has the
strongest theorem support. It is not distinctively gravitational by
itself; it is a quantum-information structure that horizons, measurement
cuts, and screened effective descriptions may instantiate in different
ways.

## What Is Achieved

The theorem-grade core is the constrained-access classification:

```text
allowed records or accessible algebra
    -> public center / redundant records
    -> protected commutant or private complement
    -> de-protected but unrecovered operators
    -> coherently exported and recoverable private information
```

The latency results give the dynamical version:

```text
local constrained access + finite routing speed
    -> private recovery has geometric lower bounds
```

Fast private recovery requires one of two mechanisms:

```text
fast routing / scrambling / coherent export

or

dressed or nonlocal access that bypasses ordinary routing
```

Within the model classes studied so far, this supports strong
separation statements: public records do not imply private recovery,
operator growth does not by itself imply coherent export, and anonymity
or compression does not by itself supply mixing.

## What The Black-Hole Model Achieves

The Hamiltonian black-hole construction is best understood as a
sufficiency and consistency result.

Given the three black-hole inputs,

```text
black-hole density of states
boundary-accessible emission
ETH-like mixing / scrambling
```

the exterior information-theoretic evaporation package composes:

```text
detailed-balance thermality
Page-like recovery
island-like algebra
state-dependent mirrors
complexity obstruction
```

This does not derive the inputs. It shows that, once the inputs are
present, many exterior information-puzzle features follow from ordinary
quantum-channel structure rather than from local geometry directly.

## The Gravitational Residue

The remaining gravitational content is now more sharply located. It is
not hidden inside the access theorems; it sits in the inputs and in the
geometric interpretation:

```text
origin of the super-Hagedorn / area-law state count

origin of boundary saturation or whole-entropy accessibility

origin of the thermal-scrambling tie

origin of local near-horizon geometry, infalling experience, and
geometric locality
```

The current rigor is strongest where the claims are most general. The
claims most specific to gravity are currently the least derived. This is
not a defect to hide; it is the program's present demarcation result.

## Best Next Test

The sharpest next target is not another restatement of horizons or
measurement cuts. It is the recovery-versus-scrambling question:

```text
Can a system have fast scrambling diagnostics while coherent private
recovery remains bounded?
```

Operationally:

```text
OTOCs / operator size / scrambling diagnostics high

but

F_export low for the allowed record partition
```

Finding such a regime would show that scrambling and recoverability are
distinct transitions. Ruling it out for broad classes would be equally
important, because it would identify conditions under which scrambling
does force coherent export.

The proposed numerical phase diagram should vary:

```text
connectivity / locality
symmetry, fragmentation, or conservation constraints
record partition
```

and measure:

```text
scrambling diagnostics
F_export or optimized recovery fidelity
optional R_public and lambda for calibration
```

## How To Read The Program Now

The achieved result is a demarcation:

```text
large parts of the black-hole information puzzle are generic
constrained-channel structure
```

The unresolved target is also clearer:

```text
derive, replace, or explain the black-hole-specific inputs that make
the constrained channel horizon-like
```

The long-term aspiration remains:

```text
understand whether horizons, measurement cuts, substrate screening, and
effective classicality are related regimes of constrained access
```

but that aspiration should now be tested through specific access/export
claims, not by metaphor.
